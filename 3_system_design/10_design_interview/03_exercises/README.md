# Упражнения: design interview

Каждая задача — это `main.go` с функцией-заготовкой (`TODO`) и встроенной самопроверкой, печатающей `PASS` или `FAIL`. Заготовки компилируются сразу (в стартовом состоянии тесты печатают `FAIL`) — ваша цель довести их до `PASS`.

Запуск шаблона:

```bash
go run ./03_exercises/01_base62/main.go
```

Запуск эталонного решения:

```bash
go run ./04_exercises_answers/01_base62_answers/main.go
```

## Список задач

1. `01_base62` — реализовать `encode`/`decode` инкрементного ID в base62 (короткий код для сокращателя ссылок), round-trip `decode(encode(id)) == id`.
2. `02_storage_estimation` — посчитать объём хранилища: размер записи × записей в сутки × дней хранения.
3. `03_qps_estimation` — посчитать средний и пиковый QPS из DAU и числа запросов на пользователя.
