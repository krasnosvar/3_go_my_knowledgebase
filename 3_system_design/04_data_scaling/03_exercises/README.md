# Упражнения: data scaling

Каждая задача — это `main.go` с функцией-заготовкой (`TODO`) и встроенной самопроверкой, печатающей `PASS` или `FAIL`. Заготовки компилируются сразу (в стартовом состоянии тесты печатают `FAIL`) — ваша цель довести их до `PASS`.

Запуск шаблона:

```bash
go run ./03_exercises/01_pick_shard/main.go
```

Запуск эталонного решения:

```bash
go run ./04_exercises_answers/01_pick_shard/main.go
```

## Список задач (от простого к сложному)

1. `01_pick_shard` — выбор шарда по хеш-ключу: `shard = hash(key) % n` через `hash/fnv`.
2. `02_reshard_moved` — доля перемещённых ключей при ре-шардинге наивного `hash%N` (oldN → newN).
3. `03_classify_cap` — определить CP или AP по описанию поведения системы при разделении сети.
4. `04_check_quorum` — проверка кворума `W + R > N` с валидацией параметров (хардкор).
