# Упражнения: System Design интервью и расчёты в Go

Каждая задача — это `main.go` с функцией/методом-заготовкой (`TODO`) и
встроенной самопроверкой, печатающей `PASS` или `FAIL`. Заготовки компилируются
сразу (в стартовом состоянии тесты печатают `FAIL`) — ваша цель довести их до
`PASS`.

Запуск шаблона:

```bash
go run ./03_exercises/01_base62/main.go
```

Запуск эталонного решения:

```bash
go run ./04_exercises_answers/01_base62_answers/main.go
```

## Список задач

1. `01_base62` — реализовать функции `encode(id uint64) string` и
   `decode(s string) uint64` для кодирования числового ID в алфавит Base62
   (`[0-9a-zA-Z]`).
2. `02_storage_estimation` — вычислить суммарный объём диска в гигабайтах,
   необходимый для хранения записей за `years` лет.
3. `03_qps_estimation` — вычислить средний (`avgQPS`) и пиковый (`peakQPS`)
   поток запросов по DAU, числу запросов на пользователя в сутки и коэффициенту
   пика.
