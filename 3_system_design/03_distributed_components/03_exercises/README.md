# Упражнения: распределённые компоненты, очереди и отказоустойчивость в Go

Каждая задача — это `main.go` с функцией/методом-заготовкой (`TODO`) и
встроенной самопроверкой, печатающей `PASS` или `FAIL`. Заготовки компилируются
сразу (в стартовом состоянии тесты печатают `FAIL`) — ваша цель довести их до
`PASS`.

Запуск шаблона:

```bash
go run ./03_exercises/01_pick_shard/main.go
```

Запуск эталонного решения:

```bash
go run ./04_exercises_answers/01_pick_shard_answers/main.go
```

## Список задач

1. `01_pick_shard` — детерминированно выбрать номер шарда `0..numShards-1` по
   строковому ключу через хеш `FNV-1a`.
2. `02_reshard_moved` — подсчитать долю ключей, меняющих шард при наивном
   изменении числа шардов `hash(key) % N → hash(key) % M`.
3. `03_classify_cap` — выбрать компромисс `CP` или `AP` для заданного
   инженерного сценария при сетевом разделении.
4. `04_check_quorum` — проверить выполнение строгого кворума ($R + W > N$) и
   доступность чтения/записи при отказе $F$ узлов.
5. `05_idempotent_handler` — реализовать идемпотентный обработчик списаний,
   защищённый от повторной доставки одного и того же `MessageID`.
6. `06_classify_guarantee` — определить гарантию доставки сообщений по
   конфигурации продюсера и консьюмера.
7. `07_partition_by_key` — распределить поток событий по $N$ партициям с
   сохранением строгого порядка внутри каждого ключа.
8. `08_outbox_drain` — реализовать функцию выгрузки событий из таблицы Outbox в
   брокер с корректной обработкой сбоев публикации.
9. `09_token_bucket_allow` — реализовать метод пополнения и расхода токенов
   `Allow(now)` в алгоритме Token Bucket.
10. `10_circuit_breaker_transitions` — реализовать переходы состояний Circuit
    Breaker (`Closed` → `Open` → `Half-Open` → `Closed`).
11. `11_backoff_sequence` — вычислить последовательность пауз экспоненциального
    backoff с ограничением сверху (`maxDelay`).
12. `12_call_with_timeout` — выполнить функцию с ограничением времени через
    `context.WithTimeout` без утечки горутины.
13. `13_fixed_window_limiter` — реализовать ограничитель скорости запросов по
    алгоритму фиксированного временного окна (Fixed Window).
