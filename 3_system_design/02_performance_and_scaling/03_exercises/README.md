# Упражнения: производительность, наблюдаемость и кэширование в Go

Каждая задача — это `main.go` с функцией/методом-заготовкой (`TODO`) и
встроенной самопроверкой, печатающей `PASS` или `FAIL`. Заготовки компилируются
сразу (в стартовом состоянии тесты печатают `FAIL`) — ваша цель довести их до
`PASS`.

Запуск шаблона:

```bash
go run ./03_exercises/01_ttl_cache/main.go
```

Запуск эталонного решения:

```bash
go run ./04_exercises_answers/01_ttl_cache_answers/main.go
```

## Список задач

1. `01_ttl_cache` — реализовать кэш с поддержкой времени жизни записи (`TTL`) и
   проверкой истечения при чтении.
2. `02_lru_cache` — реализовать LRU-кэш фиксированной ёмкости (`Get` и `Put` с
   вытеснением самого старого по обращению элемента).
3. `03_hit_ratio` — смоделировать работу кэша на потоке ключей и вычислить
   итоговый `HitRatio`.
4. `04_invalidation` — реализовать паттерн Cache-Aside с корректной
   инвалидацией кэша при обновлении и удалении данных в БД.
5. `05_red_metrics` — реализовать сборщик RED-метрик (количество запросов,
   доля ошибок, расчёт перцентиля латентности).
6. `06_prometheus_format` — отформатировать собранные метрики с лейблами в
   текстовый формат Prometheus.
7. `07_readiness_handler` — реализовать HTTP-хендлер готовности `/readyz`,
   возвращающий `200 OK` или `503 Service Unavailable` по состоянию
   зависимостей.
8. `08_parse_log_line` — разобрать структурную строку лога формата `key=value`
   в `map[string]string`.
