# Упражнения: caching

Каждая задача — это `main.go` с функцией/методом-заготовкой (`TODO`) и встроенной самопроверкой, печатающей `PASS` или `FAIL`. Заготовки компилируются сразу (в стартовом состоянии тесты печатают `FAIL`) — ваша цель довести их до `PASS`. Только стандартная библиотека, всё детерминированно.

Запуск шаблона:

```bash
go run ./03_exercises/01_ttl_cache/main.go
```

Запуск эталонного решения:

```bash
go run ./04_exercises_answers/01_ttl_cache/main.go
```

## Список задач (от простого к сложному)

1. `01_ttl_cache` — кэш с TTL: `Set(key, val, ttl)` и `Get(key)`, протухший ключ считается отсутствующим (время — через инъектируемые часы, без реального сна).
2. `02_lru_cache` — LRU-кэш: `Get`/`Put` с вытеснением least recently used при переполнении (`map` + `container/list`).
3. `03_hit_ratio` — учёт попаданий/промахов и подсчёт `hit ratio = hits / (hits + misses)` с корректной обработкой нуля обращений.
4. `04_invalidation` — cache-aside с инвалидацией на записи: `Update` удаляет ключ из кэша, следующий `Get` перечитывает свежее из «БД» (проверяется счётчиком чтений).
