# Упражнения: design principles

Каждая задача — это `main.go` с функцией/методом-заготовкой (`TODO`) и встроенной самопроверкой, печатающей `PASS` или `FAIL`. Заготовки компилируются сразу (в стартовом состоянии тесты печатают `FAIL`) — ваша цель довести их до `PASS`.

Запуск шаблона:

```bash
go run ./03_exercises/01_srp_refactor/main.go
```

Запуск эталонного решения:

```bash
go run ./04_exercises_answers/01_srp_refactor/main.go
```

## Список задач (от простого к сложному)

1. `01_srp_refactor` — SRP: разнести подсчёт суммы (`Calculator.Total`) и её форматирование (`Formatter.Format`) по разным ответственностям.
2. `02_strategy_func` — Strategy через func-тип: реализовать взаимозаменяемые стратегии цены как значения-функции.
3. `03_decorator` — Decorator: добавить поведение (`[audit]`-префикс) обёрткой вокруг интерфейса, не меняя исходный тип.
4. `04_ocp_open_closed` — **OCP через интерфейс: суммировать площади фигур без `switch` по типу (Хардкор)**.
