# Кодировки: ASCII, Unicode, UTF-8

## Что такое кодировка

Компьютер хранит только числа (байты). Чтобы работать с текстом, нужна
договорённость: **какое число соответствует какому символу**. Такая
договорённость называется **кодировкой** (encoding).

Без кодировки байт `0x41` — это просто число 65. С кодировкой ASCII мы знаем,
что 65 — это буква `A`.

## ASCII (7 бит)

ASCII — одна из первых стандартных кодировок. В ней всего **128 символов**
(коды `0`–`127`, помещаются в 7 бит):

- управляющие символы (`0`–`31`): перевод строки, табуляция и т. п.;
- печатные символы (`32`–`126`): пробел, цифры, латинские буквы, знаки
  препинания.

```
'A' = 65 = 0x41
'a' = 97 = 0x61
'0' = 48 = 0x30
' ' = 32 = 0x20
```

Проблема: 128 символов хватает только на латиницу. Как только понадобились
кириллица, греческий, китайский и другие алфавиты, каждый регион придумал свои
однобайтовые кодировки (CP1251, KOI8-R, ISO-8859-1 и десятки других). Один и
тот же байт `0xC0` в разных кодировках — это разные символы, отсюда
классические «кракозябры» при неправильной кодировке.

## Unicode — единая таблица символов

**Unicode** решает проблему национальных алфавитов: это одна большая таблица,
которая присваивает **уникальный номер каждому символу** всех письменностей
мира (а также эмодзи, символам и т. д.).

Номер символа называется **кодовой точкой** (code point) и записывается как
`U+XXXX` (шестнадцатеричное число):

```
U+0041  →  A
U+0416  →  Ж
U+20AC  →  €
U+1F600 →  😀
```

Диапазон кодовых точек: `U+0000` … `U+10FFFF` (чуть больше 1,1 млн возможных
значений).

**Важно:** Unicode — это *таблица соответствий* «символ ↔ номер», а не способ
хранения в байтах. Он говорит «буква Ж имеет номер U+0416», но не говорит,
какими именно байтами её записать в файл. За это отвечают отдельные кодировки:
UTF-8, UTF-16, UTF-32.

## UTF-8, UTF-16, UTF-32

Это разные способы закодировать кодовые точки Unicode в байты.

### UTF-8 (де-факто стандарт)

Кодировка **переменной длины**: символ занимает от 1 до 4 байт.

| Диапазон code points | Байт | Пример                   |
| -------------------- | ---- | ------------------------ |
| U+0000 … U+007F      | 1    | `A` → `41`               |
| U+0080 … U+07FF      | 2    | `Ж` → `D0 96`            |
| U+0800 … U+FFFF      | 3    | `€` → `E2 82 AC`         |
| U+10000 … U+10FFFF   | 4    | `😀` → `F0 9F 98 80`     |

Свойства UTF-8:

- **обратно совместим с ASCII**: коды `0`–`127` кодируются одним байтом, тем же
  самым, что в ASCII. Любой ASCII-файл уже является валидным UTF-8;
- **самосинхронизация**: по любому байту видно, начало это символа или его
  продолжение (ведущий байт многобайтовой последовательности начинается с
  `11...`, продолжающие — с `10...`). Если потерять байт, можно найти начало
  следующего символа;
- экономно для латиницы.

### UTF-16

Символ занимает 2 или 4 байта. Базовые символы — 2 байта, редкие (эмодзи и др.)
— 4 байта (через «суррогатные пары»). Используется внутри Windows и Java.

### UTF-32

Всегда 4 байта на символ. Просто (индексация по номеру символа тривиальна), но
расходует много места, поэтому для хранения почти не применяется.

## Таблица примеров

| Символ | Кодовая точка | Байты UTF-8    |
| ------ | ------------- | -------------- |
| `A`    | U+0041        | `41`           |
| `0`    | U+0030        | `30`           |
| `é`    | U+00E9        | `C3 A9`        |
| `Ж`    | U+0416        | `D0 96`        |
| `€`    | U+20AC        | `E2 82 AC`     |
| `😀`   | U+1F600       | `F0 9F 98 80`  |

## BOM (Byte Order Mark)

BOM — специальный маркер `U+FEFF` в начале файла. В UTF-16/UTF-32 он указывает
порядок байтов (big/little endian). В UTF-8 порядок байтов не важен, поэтому BOM
там не нужен и часто мешает (лишние байты `EF BB BF` в начале файла). Для UTF-8
BOM обычно не используют.

## Связь с Go

В Go тип `string` — это **неизменяемая последовательность байтов**, и по
соглашению она содержит текст в **UTF-8**. Тип `rune` — это псевдоним для
`int32` и представляет **одну кодовую точку Unicode**.

```go
s := "Жё"
len(s)              // 4 — это число БАЙТ (по 2 байта на символ в UTF-8)
utf8.RuneCountInString(s) // 2 — число символов (рун)

for i, r := range s {  // range по строке итерирует по рунам
    fmt.Printf("%d: %c (U+%04X)\n", i, r, r)
}
```
