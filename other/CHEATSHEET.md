## 01. Бинарные и текстовые файлы

Подробно: [01_binary_vs_text_files.md](./01_binary_vs_text_files.md).

| Характеристика | Текстовый | Бинарный |
| :--- | :--- | :--- |
| Что хранят байты | коды символов по кодировке | «сырые» данные любого смысла |
| Читаемость | любой редактор | нужна программа, знающая формат |
| Структура | строки через `\n` (иногда `\r\n`) | задаёт формат |
| Компактность | обычно меньше | обычно больше |
| Примеры | `.txt`, `.go`, `.json`, `.csv` | `.exe`, `.jpg`, `.mp3`, `.zip` |
| Число `12345` | 5 байт: `0x31 0x32 0x33 0x34 0x35` | `int16`: 2 байта `0x30 0x39` |

Физически все файлы — байты; «текстовый» — частный случай бинарного, подчинённый кодировке.

## 02. Кодировки: ASCII, Unicode, UTF-8

Подробно: [02_encodings_ascii_unicode_utf8.md](./02_encodings_ascii_unicode_utf8.md).

| Понятие | Суть |
| :--- | :--- |
| ASCII | 128 символов, 7 бит: `0–31` управляющие, `32–126` печатные; `'A'=65=0x41`, `'a'=97`, `'0'=48`, `' '=32` |
| Однобайтовые | CP1251, KOI8-R, ISO-8859-1: один байт `0xC0` — разные символы → «кракозябры» |
| Unicode | таблица «символ ↔ code point» `U+0000…U+10FFFF`; не способ хранения |
| UTF-8 | 1–4 байта, совместим с ASCII, самосинхронизация (ведущий `11...`, продолжение `10...`) |
| UTF-16 | 2 или 4 байта (суррогатные пары); Windows, Java |
| UTF-32 | всегда 4 байта |
| BOM | `U+FEFF`; в UTF-16/32 задаёт порядок байтов; в UTF-8 (`EF BB BF`) не нужен |

| Диапазон | Байт UTF-8 | Пример |
| :--- | :--- | :--- |
| `U+0000…U+007F` | 1 | `A` → `41` |
| `U+0080…U+07FF` | 2 | `é` → `C3 A9`, `Ж` → `D0 96` |
| `U+0800…U+FFFF` | 3 | `€` → `E2 82 AC` |
| `U+10000…U+10FFFF` | 4 | `😀` → `F0 9F 98 80` |

| Go | Результат |
| :--- | :--- |
| `string` | неизменяемые байты, по соглашению UTF-8 |
| `rune` | `int32`, одна кодовая точка |
| `len("Жё")` | `4` — байты |
| `utf8.RuneCountInString("Жё")` | `2` — руны |
| `for i, r := range s` | итерация по рунам, `i` — байтовый индекс |

Подробнее о строках: [1_go_basics/10_strings](../1_golang/1_go_basics/10_strings/).

## 03. Представление чисел

Подробно: [03_number_representation.md](./03_number_representation.md).

| Тип | Диапазон |
| :--- | :--- |
| беззнаковый, `n` бит | `0 … 2ⁿ−1`: `uint8` 0…255, `uint16` 0…65535 |
| знаковый (дополнительный код) | `−2ⁿ⁻¹ … 2ⁿ⁻¹−1`: `int8` −128…127 |
| `−x` в доп. коде | инвертировать биты и прибавить 1: `5=0000_0101` → `1111_1011=−5` |

| Случай | Результат в Go |
| :--- | :--- |
| `uint8: 255 + 1` | `0` |
| `uint8: 0 − 1` | `255` |
| `int8: 127 + 1` | `−128` (паники нет) |
| `0.1 + 0.2` (float64-переменные) | `0.30000000000000004` |
| `1e16 + 1 == 1e16` (float64-переменная) | `true` — младшие разряды потеряны |
| Сравнение float | `math.Abs(a-b) < 1e-9`, не `==` |
| Деньги | `int64` в копейках/центах или decimal (`github.com/shopspring/decimal`) |

| IEEE 754 | Знак | Экспонента | Мантисса |
| :--- | :--- | :--- | :--- |
| float32 | 1 бит | 8 бит | 23 бита |
| float64 | 1 бит | 11 бит | 52 бита |

## 04. Порядок байтов

Подробно: [04_endianness.md](./04_endianness.md).

| Порядок | `0x12345678` в памяти | Где |
| :--- | :--- | :--- |
| Big-endian | `12 34 56 78` (старший по младшему адресу) | сетевой порядок (TCP/IP), часть форматов файлов |
| Little-endian | `78 56 34 12` | x86, x86-64, ARM в обычном режиме |

| Задача | Код |
| :--- | :--- |
| Записать | `binary.BigEndian.PutUint32(buf, 0x12345678)` |
| Прочитать | `x := binary.BigEndian.Uint32(buf)` |
| Little-endian | `binary.LittleEndian.PutUint32` / `.Uint32` |

## 05. Кодирование, хеширование, шифрование

Подробно: [05_encoding_hashing_encryption.md](./05_encoding_hashing_encryption.md).

| Операция | Обратимо | Ключ | Зачем | Примеры |
| :--- | :--- | :--- | :--- | :--- |
| Encoding | да, тривиально | нет | совместимость, транспорт | base64 (+~33% размера), hex, percent-encoding (пробел → `%20`) |
| Hashing | нет | нет (соль ≠ ключ) | целостность, индексы, пароли | SHA-256, SHA-3; FNV, xxHash, CRC |
| Encryption | да, только с ключом | да | конфиденциальность | AES (симметричное), RSA/ECC (асимметричное) |

| Задача | Чем |
| :--- | :--- |
| Бинарные данные в JSON/URL/email | `base64.StdEncoding.EncodeToString(b)` |
| Хранить пароль | bcrypt / scrypt / argon2 с солью: `bcrypt.GenerateFromPassword(pw, bcrypt.DefaultCost)` (`golang.org/x/crypto/bcrypt`) |
| Проверить пароль | `bcrypt.CompareHashAndPassword(hash, pw)` → `nil` = верный |
| Целостность файла | криптографический хеш (SHA-256) |
| Hash-таблица, чек-сумма | некриптографический (FNV, xxHash, CRC) |
| Большой объём данных | симметричное (AES) |
| Обмен ключом без общего секрета | асимметричное; TLS: асимметрией передают ключ, трафик — AES |

## 06. Форматы сериализации

Подробно: [06_serialization_formats.md](./06_serialization_formats.md).

| Формат | Читаемость | Размер | Схема | Скорость | Кросс-язычность |
| :--- | :--- | :--- | :--- | :--- | :--- |
| JSON | высокая | средний | нет | средняя | отличная |
| XML | средняя | большой | опц. | низкая | отличная |
| YAML | высокая | средний | нет | низкая | хорошая |
| CSV | высокая | малый (плоские таблицы) | нет | высокая | хорошая |

| MessagePack | нет | малый | нет | высокая | хорошая |

| Сценарий | Формат |
| :--- | :--- |

## 07. Компиляция и линковка

Подробно: [07_compilation_linking.md](./07_compilation_linking.md).

| Подход | Когда в машкод | Старт | Скорость | Артефакт |
| :--- | :--- | :--- | :--- | :--- |
| Компиляция (Go, C, Rust) | заранее | быстрый | высокая | под платформу |
| Интерпретация (Python, Ruby) | при выполнении | мгновенный | ниже | нужен интерпретатор |

| | Статическая линковка | Динамическая |
| :--- | :--- | :--- |
| Библиотеки | внутри бинарника | `.so` / `.dll` при запуске |

| Зависимости на машине | не нужны | нужны версии библиотек |
| Обновление библиотеки | пересборка | отдельно |

| :--- | :--- |
| Сборка | `go build -o app ./cmd/app` |

| Чисто статический бинарник при cgo | `CGO_ENABLED=0 go build ...` |
| Список платформ | `go tool dist list` |

## 09. Время и часовые пояса

Подробно: [09_time_timezones.md](./09_time_timezones.md).

| Понятие | Суть |
| :--- | :--- |
| UTC | опорное время; местное = UTC + смещение |
| Unix timestamp | секунды с `1970-01-01 00:00:00 UTC`; `1720000000` → `2024-07-03T09:46:40Z` |
| DST | смещение зависит от даты; есть несуществующие и двойные местные времена |
| tzdata (IANA) | правила поясов — из базы, а не формулой |
| Wall-clock | календарное время, может прыгнуть назад (NTP, ручная правка) |
| Monotonic | только растёт — для длительностей |
| RFC 3339 | `2026-07-09T14:30:00Z`, `2026-07-09T17:30:00+03:00`; сортируется как строка |

| Задача | Код |
| :--- | :--- |
| Сейчас (wall + monotonic) | `time.Now()` |
| В UTC | `t.UTC()` |
| Длительность | `time.Since(start)`, `t2.Sub(t1)` |
| Форматировать / разобрать RFC 3339 | `t.UTC().Format(time.RFC3339)` / `time.Parse(time.RFC3339, s)` |
| Пояс для отображения | `loc, err := time.LoadLocation("Europe/Moscow")`; `t.In(loc)` |

```go
package main

import (
	"encoding/base64"
	"encoding/binary"
	"fmt"
	"time"
	"unicode/utf8"
)

func main() {
	a, b := 0.1, 0.2
	fmt.Println(a+b, a+b == 0.3) // 0.30000000000000004 false

	var u uint8 = 255
	u++
	var i int8 = 127
	i++
	fmt.Println(u, i) // 0 -128 — без паники

	s := "Жё"
	fmt.Println(len(s), utf8.RuneCountInString(s)) // 4 2
	fmt.Printf("% X\n", "€")                       // E2 82 AC

	fmt.Println(base64.StdEncoding.EncodeToString([]byte("Привет"))) // 0J/RgNC40LLQtdGC

	buf := make([]byte, 4)
	binary.BigEndian.PutUint32(buf, 0x12345678)
	fmt.Printf("% x\n", buf) // 12 34 56 78

	fmt.Println(time.Unix(1720000000, 0).UTC().Format(time.RFC3339)) // 2024-07-03T09:46:40Z
}
```

## Ловушки

- ⚠️ `len(s)` — байты, а не символы; для символов `utf8.RuneCountInString`.
- ⚠️ BOM в начале UTF-8-файла — лишние байты `EF BB BF`, ломают парсеры.
- ⚠️ Целочисленное переполнение в Go молча заворачивается — счётчик внезапно отрицательный или огромный.
- ⚠️ Константы считаются точно: `0.1+0.2 == 0.3` и `1e16+1 == 1e16` как константные выражения дают `true` и `false` — эффекты float видны только на переменных.
- ⚠️ Деньги в `float64`.
- ⚠️ Числа в байты без явного порядка → мусор на машине с другой архитектурой; для сети — big-endian.
- ⚠️ base64 — не защита: пароль в base64 = открытый текст.
- ⚠️ Пароль как `sha256(password)` → быстрый перебор и rainbow-таблицы; нужен bcrypt/argon2 + соль.
- ⚠️ gob для внешних потребителей — только Go.
- ⚠️ Переиспользовать номер удалённого поля Protobuf под новый смысл.
- ⚠️ cgo → бинарник уже не гарантированно статический.
- ⚠️ Логика завершения на SIGKILL — его нельзя перехватить; ловите SIGTERM/SIGINT.
- ⚠️ Длительность через wall-clock (`time.Now().Unix()` до/после) → отрицательный интервал при правке часов.
- ⚠️ `t.UTC()`, `t.In()`, `t.Local()`, `t.Round(0)` снимают монотонную составляющую — длительность меряйте от исходного `time.Now()`.
- ⚠️ Хранить местное время вместо UTC → баги на переходах DST.
