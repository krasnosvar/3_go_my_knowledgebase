# MongoDB: учебный стенд + материалы

Этот каталог — учебный набор по MongoDB:

- **теория/конспект** (документная модель, коллекции, индексы, репликация/шардирование)
- **практика на Docker Compose**
- **исходные вопросы/ответы** (в `interview_questions/`)

## Структура

- `exercises/`
  - `mongodb-example/` — пример работы с MongoDB на Go (`mongodb.go`)
  - `readme.sh` — команды для запуска
- `interview_questions/`
  - `basic_mongodb_questions.md` — вопросы/ответы
  - `theory.md` — конспект теории
