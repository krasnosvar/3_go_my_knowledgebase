1. мини API
CRUD: Реализовать операции для заказов с использованием ORM и на чистом SQL.
Генерация данных: Написать скрипт для наполнения базы большим количеством записей(10млн).
Аналитический запрос: Создать API-метод, который возвращает ТОП-10 пользователей, потративших больше всего денег за последний месяц.

2. Скрипт-костыль: 
Создать скрипт на обновление записей с использованием двух видов пагинации:
Через LIMIT / OFFSET и через пагинацию по id (Keyset pagination).
