# 🚀 Пошаговый гайд: CRUD‑сервис на Go + PostgreSQL

## 1. Подготовка окружения
- Установи Go (>=1.22).
- Установи PostgreSQL и создай базу `shop`.
- Создай таблицы:
  - `users(id, order_count)`
  - `orders(id, user_id, created_at)`
  - `items(id, order_id, price)`

👉 Подсказка: сначала определи схему в SQL, чтобы понимать связи.

---

## 2. Структура проекта
Создай папку и файлы:

```
crud-service/
├── main.go
├── db.go
├── handlers.go
├── models.go
└── go.mod
```

👉 Подсказка: разделение по файлам помогает держать код чистым.

---

## 3. Подключение к базе
- В `db.go` напиши функцию, которая открывает соединение с PostgreSQL.
- Используй драйвер `github.com/lib/pq`.
- Храни строку подключения в переменной окружения.

👉 Подсказка: проверь соединение через `db.Ping()`.

---

## 4. Модели
- Опиши структуры `User`, `Order`, `Item`.
- Каждая структура должна соответствовать таблице.

👉 Подсказка: пока достаточно только базовых полей (`id`, `user_id`, `price`).

---

## 5. API‑хендлеры
Тебе нужны три метода:

1. **Создание заказа**  
   - Принимает JSON с `user_id`.  
   - Вставляет запись в `orders`.  
   - Обновляет `order_count` у пользователя.  
   - Возвращает созданный `order`.

2. **Получение заказа по ID**  
   - Читает параметр `id` из URL.  
   - Достаёт заказ из таблицы `orders`.  
   - Возвращает JSON.

3. **ТОП‑10 пользователей за месяц**  
   - Делает JOIN `users + orders + items`.  
   - Считает сумму `price` за последние 30 дней.  
   - Возвращает массив из 10 пользователей.

👉 Подсказка: начни с простых SELECT/INSERT, потом добавь логику обновления.

---

## 6. Запуск сервера
- В `main.go` инициализируй базу.  
- Зарегистрируй три маршрута:
  - `/order/create`
  - `/order/get`
  - `/users/top`
- Запусти сервер на порту `:8080`.

👉 Подсказка: используй стандартный `net/http`.

---

## 7. Тестирование API
Примеры запросов:

```bash
### Создать заказ
curl -X POST -d '{"user_id":1}' http://localhost:8080/order/create

### Получить заказ
curl "http://localhost:8080/order/get?id=1"

### Получить топ-10
curl "http://localhost:8080/users/top"
```
