# AGENTS.md — Go Knowledge Base

Русскоязычная база: (a) курс «с нуля» по порядку, (b) шпаргалка для опытных.
Весь текст, комментарии и сообщения в коде — на русском.

## Структура темы

```
NN_topic/
  README.md            # зачем, пререквизиты, файлы со ссылками, как запускать, когда дальше
  01_theory/NN_*.md    # краткая теория
  02_examples/NN_*/main.go
  03_exercises/README.md + NN_name/main.go
  04_exercises_answers/NN_name_answers/main.go
```

- Папки тем и подтем нумеруются в порядке изучения (`01_`, `02_`, …); не
  перенумеровывать без нужды, при переименовании обновлять все ссылки.
- Если тема использует ещё не пройденную конструкцию — явная пометка
  «забегание вперёд» со ссылкой на тему, где она объясняется.
- В README упражнений перечислять ВСЕ задачи (без «...»).

## Шпаргалки (CHEATSHEET.md)

Цель — быстрый справочник для опытного инженера рядом с теорией.

- Где лежат:
  - по файлу на тему: `1_golang/1_go_basics/NN_*/`, `2_oop/NN_*/`,
    `3_concurrency/NN_*/`, `4_standard_library/NN_*/`,
    `3_system_design/NN_*/`;
  - один файл на раздел (мелкие темы, `##` на тему): `1_golang/5_testing/`,
    `6_real_world_go_usage/1_app_parts/`,
    `6_real_world_go_usage/2_go_apps_types_real/`, `7_under_the_hood/`,
    `8_algorithms_dsa/`, `other/`;
  - по файлу на СУБД/брокер: `2_db_kafka_redis/1_postgres/`,
    `2_kafka_rabbit_nats_redis/1_kafka/`,
    `2_kafka_rabbit_nats_redis/4_redis/`, `4_clickhouse/`, `5_mongodb/`.
- Формат: `# <Тема> — шпаргалка`, строка со ссылкой на `01_theory/` и легендой
  `⚠️ — частая ловушка`; `##`-подразделы, каждый начинается с
  `Подробно: [файл](./01_theory/NN_*.md).`; плотные таблицы «задача →
  код/команда», «когда что выбрать», сложность; в конце `## Ловушки` —
  однострочники с `⚠️`. Без прозы, 1–3 экрана.
- Содержание — только то, чему учит теория темы; версия Go указывается, где
  поведение менялось (loopvar 1.22, `cmp.Ordered` 1.21, range-over-func 1.23,
  Swiss maps 1.24 и т.п.).
- Каждый самостоятельный Go-сниппет (`package main`) проверен `go run` вне
  репозитория, вывод в комментариях совпадает. Команды CLI/SQL, требующие
  сервера, если не запускались, — пометка под заголовком шпаргалки.
- Ссылка из README темы — одна строка после вступления, до первого `##`:
  `**Уже знакомы с темой?** → [CHEATSHEET.md](./CHEATSHEET.md) — …` (для общей
  шпаргалки раздела — `../CHEATSHEET.md#якорь`; якорь-заголовки без
  backticks).
- Индекс всех шпаргалок — раздел «Шпаргалки» в корневом `README.md`,
  сгруппирован по разделам; новую шпаргалку добавлять туда.
- Синхронизация: меняете теорию (API, версии, ловушки) — обновите шпаргалку
  темы в том же изменении.

## Харнесс упражнений

Эталон:
`3_system_design/02_performance_and_scaling/03_exercises/01_ttl_cache/main.go`.

- Шапка-комментарий: условие задачи +
  `// Запуск: go run ./03_exercises/NN_name/main.go`.
- `TODO`-заготовка компилируется сразу и возвращает нулевые значения →
  печатает `FAIL`.
- `main()` с проверками (`check`-замыкание), в конце `PASS` или `FAIL`.
- Ответ `04_exercises_answers/NN_name_answers/main.go`: тот же тестовый код +
  рабочее решение → только `PASS`.
- Только stdlib, детерминированно, быстро (< 2 c), без внешней сети
  (`httptest`, `127.0.0.1:0`, `os.MkdirTemp`).

## Модули и запуск

- Корневой `go.mod` (`github.com/krasnosvar/3_go_my_knowledgebase`, `go 1.22`)
  покрывает `1_golang/` и `3_system_design/`.
- Один `package main` на папку: несколько `main` — разносить по подпапкам.
- Проекты с внешними зависимостями (`2_db_kafka_redis/**`) — отдельные
  вложенные модули со своим `go.mod`/`go.sum`.
- Запуск: из папки темы `go run ./03_exercises/NN_name`; из корня
  `go run ./1_golang/.../03_exercises/NN_name`.

## Чеклист проверки перед сдачей

1. `go build ./... && go vet ./...` из корня — чисто (артефакты сборки — не в
   репозиторий).
2. Все заготовки `03_exercises/*` компилируются и печатают `FAIL`; все
   `04_exercises_answers/*` печатают `PASS` без `FAIL`.
3. `go test ./...` там, где есть тесты (в т.ч. `-race` для `3_concurrency`).
4. Вложенные модули: `go vet ./...` в их папках.
5. Относительные ссылки во всех `.md` (вне fenced-блоков) ведут на
   существующие пути, якоря `#...` — на существующие заголовки; все ```
   закрыты.
6. Нет склеенных латиница/кириллица слов:
   `grep -rnoP '\b\w*(?:[а-яё][a-z]|[a-z][а-яё])\w*\b' --include='*.md' --include='*.go' .`
7. Шпаргалки: у каждой темы с теорией есть `CHEATSHEET.md` (или раздел общей
   шпаргалки), README темы ссылается на неё, корневой индекс «Шпаргалки»
   актуален; якоря `#...` в ссылках существуют; содержимое не расходится с
   теорией.
8. Нет пустых папок и служебных статус-заметок («в разработке», «пересобран»,
   legacy-перенос).
