# Упражнения: linked list

Каждая задача — это `main.go` с функцией/методом-заготовкой (`TODO`) и встроенной самопроверкой, печатающей `PASS` или `FAIL`. Заготовки компилируются сразу (в стартовом состоянии тесты печатают `FAIL`) — ваша цель довести их до `PASS`. Только стандартная библиотека, всё детерминированно.

Запуск шаблона (из папки темы):

```bash
go run ./03_exercises/01_append
```

Запуск эталонного решения:

```bash
go run ./04_exercises_answers/01_append_answers
```

## Список задач (от простого к сложному)

1. `01_append` — добавление в конец списка.
2. `02_prepend` — добавление в начало списка.
3. `03_find_node` — поиск узла по значению.
4. `04_delete_node` — удаление узла по значению.
5. `05_reverse_list` — разворот списка.
6. `06_merge_sorted_lists` — слияние двух отсортированных списков.
7. `07_cycle_detection` — обнаружение цикла (Floyd).
8. `08_middle_node` — поиск середины списка.
