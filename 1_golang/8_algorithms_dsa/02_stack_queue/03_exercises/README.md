# Упражнения: stack/queue

Каждая задача — это `main.go` с функцией/методом-заготовкой (`TODO`) и встроенной самопроверкой, печатающей `PASS` или `FAIL`. Заготовки компилируются сразу (в стартовом состоянии тесты печатают `FAIL`) — ваша цель довести их до `PASS`. Только стандартная библиотека, всё детерминированно.

Запуск шаблона (из папки темы):

```bash
go run ./03_exercises/01_push_pop
```

Запуск эталонного решения:

```bash
go run ./04_exercises_answers/01_push_pop_answers
```

## Список задач (от простого к сложному)

1. `01_push_pop` — стек на срезе (Push/Pop/Peek).
2. `02_enqueue_dequeue` — очередь на срезе (Enqueue/Dequeue).
3. `03_balanced_brackets` — проверка сбалансированности скобок.
4. `04_min_stack` — стек с минимумом за O(1).
5. `05_queue_two_stacks` — очередь на двух стеках.
6. `06_sliding_window_max` — максимум в скользящем окне (монотонная очередь).
7. `07_bfs_queue` — обход в ширину с очередью.
8. `08_task_scheduler` — планировщик round-robin на очереди.
