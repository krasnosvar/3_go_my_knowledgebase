# Упражнения: set

Каждая задача — это `main.go` с функцией/методом-заготовкой (`TODO`) и встроенной самопроверкой, печатающей `PASS` или `FAIL`. Заготовки компилируются сразу (в стартовом состоянии тесты печатают `FAIL`) — ваша цель довести их до `PASS`. Только стандартная библиотека, всё детерминированно.

Запуск шаблона (из папки темы):

```bash
go run ./03_exercises/01_deduplicate
```

Запуск эталонного решения:

```bash
go run ./04_exercises_answers/01_deduplicate_answers
```

## Список задач (от простого к сложному)

1. `01_deduplicate` — удаление дубликатов с сохранением порядка.
2. `02_contains_check` — множество строк: добавление и проверка.
3. `03_union` — объединение множеств.
4. `04_intersection` — пересечение множеств.
5. `05_difference` — разность множеств.
6. `06_generic_set` — generic-множество Set[T comparable].
7. `07_count_distinct` — подсчёт уникальных и первый повтор.
8. `08_permission_flags` — множество флагов на битовой маске.
