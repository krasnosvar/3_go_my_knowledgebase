# Связанные списки в Go (Linked Lists)

Связанный список — это линейная структура данных, где элементы (узлы) хранятся не в последовательных ячейках памяти, а связаны друг с другом с помощью указателей.

## Теория: Виды списков

### 🔹 Односвязный список (Singly Linked List)
- Каждый узел хранит: **данные** и **ссылку на следующий элемент**.
- Движение: только в одну сторону (вперёд).
- [Пример реализации: 01_manual_singly_list/main.go](./01_manual_singly_list/main.go)

### 🔹 Двусвязный список (Doubly Linked List)
- Каждый узел хранит: **данные**, **ссылку на следующий** и **ссылку на предыдущий** элемент.
- Движение: в обе стороны.
- В Go реализован в стандартном пакете `container/list`.
- [Базовый пример: 02_double_linked_list/main.go](./02_double_linked_list/main.go)

## Ручная реализация (Singly Linked List)

Простейшая структура узла:

```go
type Node struct {
    Value int
    Next  *Node
}
```

Базовый обход списка:
```go
for cur := head; cur != nil; cur = cur.Next {
    fmt.Println(cur.Value)
}
```

## Стандартная библиотека: container/list

Пакет `container/list` предоставляет готовую реализацию **двусвязного списка**. Элементы хранят значения типа `any` (interface{}), поэтому в них можно записывать любые данные.

### Основные методы:
- `PushBack(v)` / `PushFront(v)` — добавить в конец/начало.
- `InsertAfter(v, mark)` / `InsertBefore(v, mark)` — вставить до/после указанного элемента.
- `MoveToBack(e)` / `MoveToFront(e)` — переместить элемент.
- `Remove(e)` — удалить элемент.
- `Len()` — получить длину списка.

### Пример использования:
```go
package main

import (
    "container/list"
    "fmt"
)

func main() {
    l := list.New()
    l.PushBack("golang")     // ["golang"]
    l.PushFront("docker")    // ["docker", "golang"]
    
    // Элементы в списке - это объекты типа *list.Element
    for e := l.Front(); e != nil; e = e.Next() {
        fmt.Println(e.Value)
    }
}
```

## Когда использовать списки?

| Операция | Срезы (Slices) | Списки (Lists) |
| :--- | :--- | :--- |
| Добавление в конец | O(1) (амортизированно) | O(1) |
| Вставка в начало | O(n) | O(1) |
| Вставка в середину | O(n) | O(1) (если есть указатель на элемент) |
| Доступ по индексу | O(1) | O(n) |
| Память | Меньше (непрерывный блок) | Больше (указатели в каждом узле) |

**Вердикт:** В 99% случаев в Go лучше использовать **slices**, так как они эффективнее работают с кэшем процессора. Используйте `container/list` только если вам нужны частые вставки/удаления в середине или начале при очень больших объемах данных.
