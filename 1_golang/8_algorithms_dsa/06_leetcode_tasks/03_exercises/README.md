# Упражнения: leetcode

Каждая задача — это `main.go` с функцией/методом-заготовкой (`TODO`) и встроенной самопроверкой, печатающей `PASS` или `FAIL`. Заготовки компилируются сразу (в стартовом состоянии тесты печатают `FAIL`) — ваша цель довести их до `PASS`. Только стандартная библиотека, всё детерминированно.

Запуск шаблона (из папки темы):

```bash
go run ./03_exercises/01_arrays_merge
```

Запуск эталонного решения:

```bash
go run ./04_exercises_answers/01_arrays_merge_answers
```

## Список задач (от простого к сложному)

1. `01_arrays_merge` — слияние отсортированных массивов in-place (LeetCode 88).
2. `02_linked_list_reverse` — разворот списка: итеративно и рекурсивно (LeetCode 206).
3. `03_valid_parentheses` — валидные скобки (LeetCode 20) и минимум удалений (LeetCode 1249).
4. `04_two_sum` — Two Sum через хеш-таблицу (LeetCode 1).
5. `05_longest_substring` — самая длинная подстрока без повторов (LeetCode 3).
6. `06_min_window` — минимальное окно, содержащее все символы (LeetCode 76).
7. `07_top_k_heap` — k самых частых элементов (LeetCode 347).
8. `08_graph_bfs` — число островов на сетке (LeetCode 200).
