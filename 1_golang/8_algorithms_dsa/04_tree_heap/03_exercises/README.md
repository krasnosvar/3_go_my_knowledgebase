# Упражнения: tree/heap

Каждая задача — это `main.go` с функцией/методом-заготовкой (`TODO`) и встроенной самопроверкой, печатающей `PASS` или `FAIL`. Заготовки компилируются сразу (в стартовом состоянии тесты печатают `FAIL`) — ваша цель довести их до `PASS`. Только стандартная библиотека, всё детерминированно.

Запуск шаблона (из папки темы):

```bash
go run ./03_exercises/01_tree_height
```

Запуск эталонного решения:

```bash
go run ./04_exercises_answers/01_tree_height_answers
```

## Список задач (от простого к сложному)

1. `01_tree_height` — высота двоичного дерева.
2. `02_bst_search` — поиск в двоичном дереве поиска.
3. `03_inorder_traversal` — симметричный (in-order) обход.
4. `04_heap_push_pop` — min-heap на срезе вручную.
5. `05_k_smallest` — k наименьших элементов через кучу.
6. `06_priority_queue` — очередь с приоритетами на container/heap.
7. `07_heapify_array` — построение кучи из массива за O(n).
8. `08_tree_level_order` — обход дерева по уровням (BFS).
