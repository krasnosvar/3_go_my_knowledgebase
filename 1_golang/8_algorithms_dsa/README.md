# 8. Алгоритмы и структуры данных (Go)

Раздел для подготовки к алгоритмическим секциям собеседований и для понимания того, как устроены базовые структуры данных. Каждая тема — теория, runnable-примеры и задачи с автопроверкой `PASS`/`FAIL` на чистой стандартной библиотеке.

**Зачем:** в продакшен-коде на Go чаще всего хватает срезов и `map`, но умение выбрать структуру данных, оценить сложность и написать BFS/кучу/два указателя без подсказок проверяют почти на каждом собеседовании.

**Уже знакомы с темой?** → [CHEATSHEET.md](./CHEATSHEET.md) — что выбрать, таблицы сложности, `container/heap`, алгоритмы на графах, паттерны задач и лимиты по n, ловушки.

**Пререквизиты:** [1_go_basics](../1_go_basics/) целиком (особенно [06_pointers](../1_go_basics/06_pointers/), [09_slices](../1_go_basics/09_slices/), [11_maps](../1_go_basics/11_maps/)) и [2_oop](../2_oop/) (методы, интерфейсы, generics).

## Как запускать

Команды выполняются из папки темы, корневой `go.mod` репозитория подхватывается автоматически:

```bash
cd 1_golang/8_algorithms_dsa/01_linked_list
go run ./02_examples/01_manual_singly_list          # пример
go run ./03_exercises/01_append                     # задача: FAIL, пока не решена
go run ./04_exercises_answers/01_append_answers     # эталонное решение: PASS
```
