# Упражнения: graph

Каждая задача — это `main.go` с функцией/методом-заготовкой (`TODO`) и встроенной самопроверкой, печатающей `PASS` или `FAIL`. Заготовки компилируются сразу (в стартовом состоянии тесты печатают `FAIL`) — ваша цель довести их до `PASS`. Только стандартная библиотека, всё детерминированно.

Запуск шаблона (из папки темы):

```bash
go run ./03_exercises/01_build_graph
```

Запуск эталонного решения:

```bash
go run ./04_exercises_answers/01_build_graph_answers
```

## Список задач (от простого к сложному)

1. `01_build_graph` — построение списка смежности.
2. `02_bfs_path` — кратчайший путь BFS в невзвешенном графе.
3. `03_dfs_path` — поиск пути обходом в глубину.
4. `04_connected_components` — подсчёт компонент связности.
5. `05_cycle_detect` — цикл в ориентированном графе (три цвета).
6. `06_topological_sort` — топологическая сортировка (Кан).
7. `07_shortest_path_unweighted` — расстояния от источника (BFS).
8. `08_is_bipartite` — проверка двудольности (раскраска в 2 цвета).
