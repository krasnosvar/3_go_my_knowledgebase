# Упражнения: Unit tests

Самопроверка в этом разделе — сам `go test`:

- **«напишите тест»** (большинство задач): рядом с кодом лежит `*_test.go`
  с заглушкой `t.Fatal("TODO ...")`, поэтому в стартовом состоянии
  `go test` печатает `FAIL`. Напишите проверки, удалите `t.Fatal` — тест
  должен стать `ok`. Чтобы убедиться, что тест действительно что-то ловит,
  временно сломайте код под тестом: тест обязан упасть.
- **«почините код»** (задачи 02–04 в `04_benchmarks`): тест уже написан и
  падает, править нужно только код под тестом.

Запуск (из папки `01_unit_tests`):

```bash
go test -v ./03_exercises/01_sum/
```

Эталонное решение:

```bash
go test -v ./04_exercises_answers/01_sum_answers/
```

## Список задач

1. `01_sum` — первый тест: пустой слайс, один и несколько элементов.
2. `02_error_branch` — покрыть все ветки ошибок `ParseAge`, сравнение через `errors.Is`.
3. `03_zero_value` — нулевое значение `Stack` пригодно к работе.
4. `04_bounds` — граничные значения `Clamp` вокруг каждой границы.
5. `05_format` — точное сравнение форматированных строк `FormatBytes`.
6. `06_parser` — тест парсера `key=value`: `maps.Equal` и ошибочные входы.
7. `07_integration_boundary` — тест через `io.Reader` вместо файла, свой `errReader`.
