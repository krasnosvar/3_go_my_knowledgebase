# Упражнения: Table-driven tests

Самопроверка в этом разделе — сам `go test`:

- **«напишите тест»** (большинство задач): рядом с кодом лежит `*_test.go`
  с заглушкой `t.Fatal("TODO ...")`, поэтому в стартовом состоянии
  `go test` печатает `FAIL`. Напишите проверки, удалите `t.Fatal` — тест
  должен стать `ok`. Чтобы убедиться, что тест действительно что-то ловит,
  временно сломайте код под тестом: тест обязан упасть.
- **«почините код»** (задачи 02–04 в `04_benchmarks`): тест уже написан и
  падает, править нужно только код под тестом.

Запуск (из папки `02_table_driven_tests`):

```bash
go test -v ./03_exercises/01_basic_table/
```

Эталонное решение:

```bash
go test -v ./04_exercises_answers/01_basic_table_answers/
```

## Список задач

1. `01_basic_table` — первая таблица для `IsPalindrome` (в том числе кириллица).
2. `02_error_cases` — поле `wantErr` и `errors.Is` в таблице `Divide`.
3. `03_slice_result` — ожидание-слайс: `slices.Equal` vs `reflect.DeepEqual`.
4. `04_map_table` — таблица-map с именами случаев и `t.Run`.
