# Упражнения: Mocks, fakes, spies

Самопроверка в этом разделе — сам `go test`:

- **«напишите тест»** (большинство задач): рядом с кодом лежит `*_test.go`
  с заглушкой `t.Fatal("TODO ...")`, поэтому в стартовом состоянии
  `go test` печатает `FAIL`. Напишите проверки, удалите `t.Fatal` — тест
  должен стать `ok`. Чтобы убедиться, что тест действительно что-то ловит,
  временно сломайте код под тестом: тест обязан упасть.
- **«почините код»** (задачи 02–04 в `04_benchmarks`): тест уже написан и
  падает, править нужно только код под тестом.

Запуск (из папки `05_mocks`):

```bash
go test -v ./03_exercises/01_fake_repo/
```

Эталонное решение:

```bash
go test -v ./04_exercises_answers/01_fake_repo_answers/
```

## Список задач

1. `01_fake_repo` — in-memory `fakeRepo` и проверка, что `Save` вызван (или нет).
2. `02_error_injection` — fake с внедряемой ошибкой, проверка обёртки через `errors.Is`.
3. `03_fake_clock` — `fixedClock` для детерминированного теста по времени суток.
4. `04_spy_calls` — spy: порядок вызовов и остановка на первой ошибке.
