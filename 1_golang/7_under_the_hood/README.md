# Go Under The Hood

Единый раздел низкоуровневых тем.

## Разделы

- `01_runtime/` — runtime internals (унифицирован по эталону, старые файлы в `_legacy_flat`).
- `02_memory_gc/` — память и GC (заполнен по эталону).
- `03_compiler/` — компилятор, модули и структура исходников.
- `04_profiling/` — pprof и профилирование.
- `05_reflection_unsafe/` — reflection и unsafe темы.
- `_legacy/` — исходные старые папки до объединения.
