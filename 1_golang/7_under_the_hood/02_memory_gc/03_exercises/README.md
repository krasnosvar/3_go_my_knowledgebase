# Упражнения: memory and GC

Каждая задача — `main.go` с заготовкой (`TODO`) и встроенной самопроверкой,
печатающей `PASS` или `FAIL`. Заготовки компилируются сразу и в стартовом
состоянии печатают `FAIL`. Аллокации измеряются через
`testing.AllocsPerRun` — его можно вызывать и из обычной `main`.

Запуск (из папки `02_memory_gc`):

```bash
go run ./03_exercises/01_stack_vs_heap
```

Эталонное решение:

```bash
go run ./04_exercises_answers/01_stack_vs_heap_answers
```

## Список задач

1. `01_stack_vs_heap` — убрать промежуточный слайс и получить 0 аллокаций.
2. `02_escape_reason` — назвать причину escape для пяти функций (указатель, глобальная переменная, замыкание, интерфейс, нет).
3. `03_gc_percent` — посчитать цель следующего GC по `GOGC` и временно изменить `debug.SetGCPercent`.
4. `04_pool_usage` — `sync.Pool` для `bytes.Buffer` с обязательным `Reset`.
5. `05_zero_alloc_loop` — `strconv.AppendInt` вместо `fmt.Sprintf`: цикл без аллокаций.
6. `06_slice_reuse` — фильтрация на месте через `s[:0]` без нового массива.
7. `07_finalizer_risk` — явный идемпотентный `Close` вместо надежды на финализатор.
8. `08_memory_budget` — оценить размер слайса и сколько элементов влезает в бюджет памяти.
