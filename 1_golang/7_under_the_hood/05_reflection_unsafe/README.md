# Reflection and unsafe

Низкоуровневые инструменты Go для интроспекции и обхода системы типов.

## Что внутри

- `01_reflection.md` — пакет `reflect`: интроспекция типов, чтение/запись полей через рефлексию, теги struct, типичные use-cases (json, ORM, валидаторы).
- `02_unsafe.md` — пакет `unsafe`: сценарии использования и почему их обычно нужно избегать.

## Когда нужны

- **reflect**: парсеры универсального вида (encoding/json, ORM), фреймворки валидации, тестовые утилиты.
- **unsafe**: интероп с C, экстремальная оптимизация (`string` ↔ `[]byte` без копии), специальные lock-free структуры.

## Цена

- Reflection — медленнее обычного кода в 10-100 раз. В hot path — почти всегда нет.
- Unsafe — обходит проверки рантайма. Один неверный layout — UB.

## Правило

В прикладном коде встречаться не должны. Все альтернативы пробуются раньше: типизированные API, generics, code generation.
