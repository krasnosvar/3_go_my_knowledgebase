# Runtime overview

Go runtime — это среда выполнения, встроенная в каждый бинарник. Она управляет:

- планировщиком горутин;
- памятью (heap, stack growth);
- сборщиком мусора (GC);
- системными вызовами и сетью;
- type system support (interface, reflect).

Это не виртуальная машина в смысле JVM — runtime компилируется внутрь твоего бинарника и работает в одном процессе с твоим кодом.

## Ключевые компоненты

- **Scheduler** — модель GMP (см. соседний файл).
- **Memory allocator** — TCMalloc-подобный, разделён на классы размера, lock-free per-P.
- **GC** — concurrent triколор. С Go 1.5 паузы STW обычно < 1 ms.
- **Network poller** — `epoll`/`kqueue`/`IOCP` под капотом, скрытый за `net.Conn`.
- **Stack management** — каждая горутина имеет свой стек, растёт динамически.

## Диагностика runtime

Пакет `runtime` даёт API:

```go
runtime.NumGoroutine()       // сколько горутин живо
runtime.NumCPU()             // сколько ядер видит процесс
runtime.GOMAXPROCS(0)        // сколько P доступно (0 = read-only)
runtime.GC()                 // принудительная сборка
runtime.ReadMemStats(&ms)    // полная статистика памяти
runtime.Stack(buf, true)     // дамп стеков всех горутин
```

Через эти вызовы строятся health-checks, debug-эндпоинты, тесты.

## GODEBUG

Переменная окружения `GODEBUG` включает диагностику:

- `GODEBUG=schedtrace=1000` — раз в секунду лог состояния планировщика.
- `GODEBUG=gctrace=1` — лог каждого GC цикла.
- `GODEBUG=allocfreetrace=1` — лог каждой аллокации (очень громко).

Используется на dev/staging, не в prod.

## GOGC и GOMEMLIMIT

- `GOGC` (по умолчанию 100) — контроль агрессивности GC. 200 = реже, больше памяти. 50 = чаще, меньше памяти.
- `GOMEMLIMIT` (Go 1.19+) — мягкий лимит общей памяти. GC учитывает его.

## Что обычно не нужно знать

В прикладном коде Go runtime скрыт. Знать о нём важно когда:

- ты диагностируешь проблему производительности;
- ты строишь сервис с миллионами горутин;
- ты подбираешь GC настройки под нагрузку.

Большинство приложений работают на defaults и нормально себя чувствуют.
