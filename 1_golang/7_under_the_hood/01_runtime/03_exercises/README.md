# Упражнения: runtime internals

Каждая задача — `main.go` с заготовкой (`TODO`) и встроенной самопроверкой,
печатающей `PASS` или `FAIL`. Заготовки компилируются сразу и в стартовом
состоянии печатают `FAIL`. Проверки детерминированы: сверяются инварианты
(«не меньше», «вернулось к исходному»), а не точные числа runtime.

Запуск (из папки `01_runtime`):

```bash
go run ./03_exercises/01_goroutine_states
```

Эталонное решение:

```bash
go run ./04_exercises_answers/01_goroutine_states_answers
```

## Список задач

1. `01_goroutine_states` — запустить n горутин в состоянии ожидания и убедиться, что `runtime.NumGoroutine()` растёт и возвращается к исходному.
2. `02_stack_growth` — стартовый размер стека и глубокая рекурсия, которая работает благодаря росту стека.
3. `03_escape_prediction` — предсказать stack/heap для пяти функций; проверка через `go build -gcflags=-m`.
4. `04_gc_observation` — посчитать циклы GC за время работы функции через `MemStats.NumGC`.
5. `05_scheduler_fairness` — тугие циклы при `GOMAXPROCS(1)`: асинхронное вытеснение даёт время каждому воркеру.
6. `06_work_stealing` — параллельная сумма: нарезка работы по горутинам и крайние случаи.
7. `07_gomaxprocs_tuning` — временно изменить `GOMAXPROCS` и гарантированно восстановить (в том числе после паники).
8. `08_runtime_metrics` — читать метрики через `runtime/metrics` и обрабатывать неподдерживаемые имена.
