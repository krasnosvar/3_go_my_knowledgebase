# Типы реальных Go-приложений

Этот раздел — навигация по типам приложений. Детальная теория, примеры структуры и задания находятся внутри README каждой подпапки.

## Оглавление (папки)

- [1_cli_tools/](./1_cli_tools/) — CLI утилиты (cobra/flag), команды, конфиг
- [2_backend/](./2_backend/) — HTTP backend (REST), middleware, БД
- [3_system_apps/](./3_system_apps/) — системные утилиты/демоны (linux), сигналы, файлы
- [4_grpc_services/](./4_grpc_services/) — gRPC сервисы, protobuf, interceptors
- [5_workers_cron/](./5_workers_cron/) — воркеры/джобы/cron, очереди, ретраи
- [6_k8s_operators/](./6_k8s_operators/) — Kubernetes operator/controller
- [7_streaming_data/](./7_streaming_data/) — стриминг/консьюмеры (Kafka/NATS), at-least-once

## Статус наполнения

- Готово по эталону: `1_cli_tools/`, `2_backend/`, `3_system_apps/`, `4_grpc_services/`, `5_workers_cron/`, `6_k8s_operators/`, `7_streaming_data/`.
