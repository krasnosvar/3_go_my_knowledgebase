# Real world Go usage

Этот раздел про Go **в контексте реального рабочего приложения**.

Идея:
- здесь мы не раскладываем материалы строго по "темам" (testing/http/db…), потому что в реальном проекте они всегда идут вместе;
- вместо этого:
  - в `1_app_parts/` собираем **части приложения** (как кубики), которые обычно проектируют через интерфейсы и удобно мокают в тестах;
  - в `2_go_apps_types_real/` описываем **типы реальных Go-приложений** и как они обычно устроены (архитектура, слои, структура пакетов).

## Оглавление

- [1_app_parts/](./1_app_parts/) — части реального приложения (и как их тестировать/мокать)
- [2_go_apps_types_real/](./2_go_apps_types_real/) — типы реальных приложений на Go (примеры архитектуры)

## Статус наполнения

- `1_app_parts/` — заполнен по эталону (8 блоков приложения).
- `2_go_apps_types_real/` — заполнен по эталону (7 типов приложений).
