# Тема 10. Строки (Strings)

Этот раздел посвящен детальному изучению работы со строками в Go: отличиям байтов от рун, внутреннему представлению String Header, нюансам итерации по UTF-8, накладным расходам при конвертации типов и оптимизации сборки строк через `strings.Builder`.

## 📋 Пререквизиты

*   Пройдена предыдущая тема: [09_slices](../09_slices/).
*   Справочно (по желанию): [кодировки ASCII/Unicode/UTF-8](../../../other/02_encodings_ascii_unicode_utf8.md) и [как компьютер хранит числа](../../../other/03_number_representation.md).

> ⏩ **Забегание вперёд.** Некоторые примеры и упражнения используют конструкции из следующих тем:
> *   `06_unsafe_conversions` использует пакет `unsafe` — подробно в [7_under_the_hood/05_reflection_unsafe](../../7_under_the_hood/05_reflection_unsafe/). Задачу можно отложить.

## 🗂 Структура раздела

*   **[01_theory/](./01_theory/)** — теория (разбита по подтемам):
    *   [01_basics_immutability.md](./01_theory/01_basics_immutability.md) — основы: устройство String Header (указатель + длина), неизменяемость и read-only память, литералы строк, `len` как длина в байтах, проверка подстрок через пакет `strings`.
    *   [02_bytes_runes_utf8.md](./01_theory/02_bytes_runes_utf8.md) — байты vs руны, кодировка UTF-8 переменной длины, тип `rune` (`int32`), разница побайтового обхода `for` и порунного `for range` (скачущие индексы).
    *   [03_conversions.md](./01_theory/03_conversions.md) — конвертации `string` ↔ `[]byte`/`[]rune`, копирование данных и аллокации, нагрузка на сборщик мусора.
    *   [04_builder_and_concat.md](./01_theory/04_builder_and_concat.md) — почему конкатенация через `+` в цикле — антипаттерн, `strings.Builder`, метод `Grow()` и сборка строки без лишних аллокаций.
    *   [05_use_cases.md](./01_theory/05_use_cases.md) — сводка практических сценариев и ловушек: подсчёт символов вместо байтов, корректные индексы, изменение символа, аллокации при конвертации, сборка строк в цикле.
*   **[02_examples/](./02_examples/)** — практические примеры:
    *   [01_cli_utilities](./02_examples/01_cli_utilities/main.go) — демонстрация разницы между длиной строки в байтах (`len`) и количеством рун (`utf8.RuneCountInString`) при обработке Unicode-файлов и аргументов.
    *   [02_system_infrastructure](./02_examples/02_system_infrastructure/main.go) — бенчмарк-сравнение скорости и аллокаций обычной конкатенации строк (`+`) и оптимизированного `strings.Builder` с вызовом `Grow()`.
    *   [03_product_backend](./02_examples/03_product_backend/main.go) — **валидация надежности пароля с помощью пакета `unicode` (проверка типов рун: заглавные буквы, цифры)**.
*   **[03_exercises/](./03_exercises/)** — интерактивные задачи для самопроверки с автопроверками `PASS`/`FAIL`:
    *   `01_string_basics` — подсчет длины строки в байтах и рунах.
    *   `02_utf8_runes` — декодирование первого символа строки и определение его размера.
    *   `03_concat_builder` — сборка строки из массива слов через `strings.Builder` с оптимизацией `Grow()`.
    *   `04_immutability` — модификация символа строки через приведение к слайсу рун.
    *   `05_safe_substring` — **безопасное извлечение подстроки по индексам символов (рун), исключающее повреждение UTF-8 байт**.
    *   `06_unsafe_conversions` — **реализация zero-copy (без выделения памяти) конвертации между `[]byte` и `string` с помощью пакета `unsafe`**.
    *   `07_normalization` — нормализация тегов (trim, lower, слияние пробелов в дефис).
    *   `08_parsing` — парсинг параметров конфигурации формата `key=value` с обрезкой пробелов.
*   **[04_exercises_answers/](./04_exercises_answers/)** — эталонные решения.

## 🚀 Как проходить тему

1. Прочитайте теорию по порядку, начиная с [01_basics_immutability.md](./01_theory/01_basics_immutability.md).
2. Запустите и изучите примеры из папки `02_examples/` через `go run`:
   ```bash
   go run ./02_examples/02_system_infrastructure/main.go
   ```
3. Выполните задачи в `03_exercises/`. Запустите встроенный тест для самопроверки:
   ```bash
   go run ./03_exercises/05_safe_substring/main.go
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.
