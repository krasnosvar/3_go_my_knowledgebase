# Строки — шпаргалка

Подробности и объяснения — в [01_theory/](./01_theory/). ⚠️ — частая ловушка.
Функции пакета `strings` подробно — в [4_standard_library/01_fmt_strconv_strings](../../4_standard_library/01_fmt_strconv_strings/).

## Устройство и литералы

Подробно: [01_basics_immutability.md](./01_theory/01_basics_immutability.md).

| Факт | Детали |
| :--- | :--- |
| Заголовок строки | 16 байт (64 бит): указатель на байты + длина; передача в функцию копирует только его |
| Неизменяемость | `s[0] = 'x'` не компилируется; данные строки — read-only |
| Нулевое значение | `""` (не `nil`) |
| Интерпретируемый литерал | `"a\tb\n"` — escape-последовательности работают |
| Сырой литерал | `` `a\nb` `` — без escape, с переносами; `len` = 4 |
| `len(s)` | число **байтов**: `len("Привет")` = 12 |
| Индекс `s[i]` | `byte` (`uint8`), а не символ |
| Сравнение | `==`, `<` — побайтово (лексикографически) |

## Байты, руны, UTF-8

Подробно: [02_bytes_runes_utf8.md](./01_theory/02_bytes_runes_utf8.md).

| Символы | Байт в UTF-8 |
| :--- | :--- |
| ASCII (латиница, цифры) | 1 |
| Кириллица | 2 |
| Иероглифы, большинство эмодзи | 3–4 |

| Задача | Код |
| :--- | :--- |
| Тип символа | `rune` = `int32` (Unicode code point); `byte` = `uint8` |
| Число символов | `utf8.RuneCountInString(s)` или `len([]rune(s))` |
| Обход по байтам | `for i := 0; i < len(s); i++ { s[i] }` |
| Обход по рунам | `for i, r := range s {}` — `i` — смещение в байтах |
| Символ по номеру | `[]rune(s)[n]` |
| Печать | `%c` — руна, `%q` — в кавычках, `%x` — hex байтов, `%U` — `U+041F` |

```go
for i, r := range "Пр" {
	fmt.Print(i, ":", string(r), " ") // 0:П 2:р — индексы скачут на 2
}
```

## Конвертации и аллокации

Подробно: [03_conversions.md](./01_theory/03_conversions.md).

| Конвертация | Стоимость |
| :--- | :--- |
| `[]byte(s)` | аллокация + копия; правка копии не меняет `s` |
| `[]rune(s)` | аллокация + декодирование UTF-8 |
| `string(b)` / `string(r)` | аллокация + копия |
| `string(rune(65))` | `"A"` — символ; число в текст — `strconv.Itoa` |

| Изменить символ | Код |
| :--- | :--- |
| Любой текст | `r := []rune(s); r[0] = 'п'; s = string(r)` |
| Только ASCII | `b := []byte(s); b[0] = 'h'; s = string(b)` |

## Сборка строк

Подробно: [04_builder_and_concat.md](./01_theory/04_builder_and_concat.md).

| Способ | Когда |
| :--- | :--- |
| `a + b` | пара фиксированных частей |
| `s += x` в цикле | ❌ O(n²): каждая итерация копирует накопленное |
| `strings.Builder` | сборка в цикле; `String()` возвращает строку без копирования |
| `b.Grow(n)` | итоговый размер известен заранее → одна аллокация |
| `strings.Join(parts, ",")` | готовый слайс строк |
| `fmt.Sprintf` | форматирование; медленнее Builder в горячем цикле |

```go
var b strings.Builder
b.Grow(16)
for i := 0; i < 3; i++ {
	b.WriteString("go") // также WriteByte, WriteRune, fmt.Fprintf(&b, ...)
}
fmt.Println(b.String(), b.Len()) // gogogo 6
```

## Частые функции strings

| Задача | Код |
| :--- | :--- |
| Подстрока есть? | `strings.Contains(s, "иве")` |
| Префикс / суффикс | `strings.HasPrefix(s, "Пр")`, `strings.HasSuffix(s, "т")` |
| Позиция (в байтах) | `strings.Index(s, sub)` → `-1`, если нет |
| Разбить / склеить | `strings.Split(s, ",")`, `strings.Fields(s)`, `strings.Join(xs, ",")` |
| Обрезать | `strings.TrimSpace(s)`, `strings.TrimPrefix(s, "v")` |
| Регистр | `strings.ToLower`, `strings.ToUpper`, `strings.EqualFold(a, b)` |
| Замена | `strings.ReplaceAll(s, old, new)` |

## Ловушки

- ⚠️ `len(s)` — байты, не символы; для кириллицы и эмодзи считать через `utf8.RuneCountInString`.
- ⚠️ `s[i]` и срез `s[a:b]` работают по байтам — можно разрезать символ пополам и получить невалидный UTF-8.
- ⚠️ Индекс в `for range` — смещение в байтах, а не номер символа.
- ⚠️ `string(n)` для `n := 65` даёт `"A"`, а не `"65"` (`go vet` предупреждает); нужен `strconv.Itoa(n)`.
- ⚠️ `+=` в цикле — квадратичное время и мусор для GC.
- ⚠️ Частые `string` ↔ `[]byte` в горячем цикле — лишние аллокации.
- ⚠️ Подстрока большой строки удерживает её целиком в памяти; отвязать — `strings.Clone` (1.18+).
- ⚠️ Копировать `strings.Builder` после первой записи нельзя — panic; передавать по указателю.
