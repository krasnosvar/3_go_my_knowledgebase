# Преобразования типов и аллокации

Когда вы преобразуете строку в слайс байт `[]byte(str)` или слайс рун `[]rune(str)`, Go **выделяет память и полностью копирует данные**, чтобы гарантировать неизменяемость исходной строки.

```go
s := "hello"
b := []byte(s) // Выделение памяти + копирование!
b[0] = 'z'     // s не изменится, s по-прежнему "hello"
```

Если строка очень большая, частые преобразования `string` ↔ `[]byte` вызовут серьезную нагрузку на сборщик мусора.

ASCII-схема копирования при конвертации:

```
string "hello" (read-only)      []byte (изменяемая копия)
┌──────────────┐   копия        ┌──────────────┐
│ h e l l o    │ ─────────────→ │ h e l l o    │
└──────────────┘                └──────────────┘
```
