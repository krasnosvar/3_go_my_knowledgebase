# Строки в Go: основы и неизменяемость

## Что такое строка в Go

Под капотом строка в Go — это структура фиксированного размера (16 байт на 64-битных системах), состоящая из указателя на данные и длины. В пакете `reflect` заголовок представлен следующим образом:

```go
type StringHeader struct {
    Data uintptr // Указатель на массив байтов
    Len  int     // Длина строки в байтах
}
```

Поскольку строка содержит только указатель и длину, передача строки в функцию происходит чрезвычайно быстро (копируются только эти 16 байт), независимо от размера самой строки.

ASCII-схема заголовка строки:

```
string "hello"
┌──────────┬───────┐
│ Data ────┼──→ [ 'h' 'e' 'l' 'l' 'o' ]  (read-only)
│ Len = 5  │
└──────────┴───────┘
```

## Неизменяемость (immutability)

Строки в Go **неизменяемы** (immutable). Вы не можете поменять отдельный символ в строке напрямую.

Сами данные строки хранятся в read-only области памяти. Попытка изменить байт по указателю `Data` приведет к панике времени выполнения.

## Литералы строк

* Двойные кавычки `"..."` поддерживают escape-последовательности (`\n`, `\t`).
* Обратные кавычки `` `...` `` создают сырые (raw) строки, сохраняющие переносы строк и кавычки.

## Длина строки

Функция `len(str)` возвращает **количество байтов**, а не количество символов!

> ⚠️ Частый вопрос на собеседовании: чему равно `len("Привет")`? Ответ — 12, а не 6, потому что каждый символ кириллицы в UTF-8 занимает 2 байта.

## Проверка подстрок

Для проверки подстрок используйте функции пакета `strings`:

* `strings.Contains`
* `strings.HasPrefix`
* `strings.HasSuffix`
