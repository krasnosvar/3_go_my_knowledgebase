# Байты против рун (UTF-8)

В Go все строки кодируются в UTF-8. UTF-8 — это кодировка переменной длины:

* Символы латиницы (ASCII) занимают **1 байт**.
* Символы кириллицы занимают **2 байта**.
* Иероглифы и эмодзи могут занимать **3 или 4 байта**.

Тип `rune` в Go — это просто синоним типа `int32`. Он представляет собой числовой код символа (Unicode Code Point).

## Итерация по строкам

Существует два способа обойти строку в цикле, и они работают совершенно по-разному:

```go
str := "Привет" // 6 символов, но 12 байт в UTF-8
```

### Способ А: обычный цикл `for` (побайтовый обход)

```go
for i := 0; i < len(str); i++ {
    fmt.Printf("%x ", str[i]) // Выводит сырые байты: d0 9f d1 80...
}
```

### Способ Б: цикл `for range` (порунно с декодированием)

`for range` автоматически декодирует UTF-8:

```go
for idx, r := range str {
    fmt.Printf("Индекс: %d, Символ: %c\n", idx, r)
}
```

> ⚠️ Частый вопрос на собеседовании: индексы в `for range` будут скакать! Для кириллицы они пойдут: `0, 2, 4, 6...`, так как каждый символ занимает 2 байта. Это критично для работы с кириллицей или эмодзи.
