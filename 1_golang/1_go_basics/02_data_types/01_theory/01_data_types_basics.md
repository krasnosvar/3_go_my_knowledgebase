# Система типов в Go: обзор

Go — язык со **строгой статической типизацией**. Каждый тип определяет точный формат представления данных в памяти и набор допустимых операций. Неявного приведения типов нет: даже безопасные конверсии нужно писать явно (подробнее — в `05_conversions.md`).

Это вводный файл по системе типов. Он даёт общую карту: какие бывают категории типов и куда смотреть за деталями. Числовые типы, строки/`byte`/`rune`, нулевые значения и приведение типов разобраны в отдельных файлах.

## Справочная таблица типов данных

В Go все типы разделены по размеру, поведению при передаче в функции и сравнимости:

| Категория | Тип | Размер (64-bit) | Нулевое значение | Сравнимый | Передача |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Простые** | `bool` | 1 байт | `false` | ✅ | По значению |
| | `int8`, `uint8` (`byte`) | 1 байт | `0` | ✅ | По значению |
| | `int16`, `uint16` | 2 байта | `0` | ✅ | По значению |
| | `int32` (`rune`), `uint32` | 4 байта | `0` | ✅ | По значению |
| | `int64`, `uint64` | 8 байт | `0` | ✅ | По значению |
| | `int`, `uint` | 8 байт | `0` | ✅ | По значению |
| | `float32` | 4 байта | `0.0` | ✅ (осторожно) | По значению |
| | `float64` | 8 байт | `0.0` | ✅ (осторожно) | По значению |
| | `complex64` | 8 байт | `0 + 0i` | ✅ | По значению |
| | `complex128` | 16 байт | `0 + 0i` | ✅ | По значению |
| **Составные** | `[N]T` (Массив) | `N * sizeof(T)` | Массив нулей | ✅ (если `T` сравним) | Копирование массива |
| | `struct` | Сумма полей + padding | Нулевые поля | ✅ (если все поля сравнимы) | Копирование структуры |
| **Ссылочные** | `*T` (Указатель) | 8 байт | `nil` | ✅ | По значению (адрес) |
| | `[]T` (Слайс) | 24 байта | `nil` | ❌ (только с `nil`) | По значению заголовка |
| | `map[K]V` | 8 байт (указатель)| `nil` | ❌ (только с `nil`) | По значению (указатель) |
| | `chan T` (Канал) | 8 байт (указатель)| `nil` | ✅ | По значению (указатель) |
| **Специальные**| `func(...)` | 8 байт (указатель)| `nil` | ❌ (только с `nil`) | По значению (указатель) |

> [!NOTE]
> Слайсы, мапы и функции нельзя сравнивать между собой через `==`. Их можно сравнивать только с `nil`. Для глубокого сравнения слайсов/мап используйте `reflect.DeepEqual()` или встроенный пакет `slices.Equal()` (начиная с Go 1.21).

Полная таблица нулевых значений и нюансы `nil`-типов — в `04_zero_values.md`.

## Категории типов (краткий обзор)

### Числовые типы

Целые (`int8`…`int64`, `uint8`…`uint64`, `int`/`uint`, `uintptr`), числа с плавающей точкой (`float32`, `float64`) и комплексные (`complex64`, `complex128`). Диапазоны, размеры, переполнение и особенности сравнения float — в `02_numeric_types.md`.

### Логический тип (bool)

Тип `bool` принимает два значения: `true` и `false`. Нулевое значение — `false`. Занимает 1 байт. В Go нет неявного приведения чисел к `bool`: условие в `if` должно быть булевым выражением.

### Строки, byte и rune

`string` — неизменяемая последовательность байтов в UTF-8. `byte` (алиас `uint8`) — один байт, `rune` (алиас `int32`) — один Unicode code point. Внутреннее устройство строки, итерация и конверсии — в `03_string_byte_rune.md`.

### Составные и ссылочные типы

Массивы (`[N]T`), структуры (`struct`), слайсы (`[]T`), мапы (`map[K]V`), указатели (`*T`), каналы (`chan T`), функции и интерфейсы. Здесь они даны обзорно; их устройство и представление в памяти показано ниже, а подробно каждый из них разбирается в соответствующих темах базы знаний.

## Представление типов в памяти

Понимание того, как типы лежат в памяти, помогает писать оптимальный по производительности и потреблению памяти код.

### Строки (string)
Строка в Go — это структура из двух полей: указателя на область памяти с байтами (backing array) и длины строки. Строки неизменяемы (immutable).

```
строка "Hello" в памяти (16 байт):
+-------------------+-------------------+
| ptr (*byte)       | len = 5 (int)     |
| 8 байт            | 8 байт            |
+--------+----------+-------------------+
         |
         v указывает на массив байт (read-only):
         ['H', 'e', 'l', 'l', 'o']
```

### Слайсы ([]T)
Слайс — это заголовок (slice header), содержащий указатель на базовый массив, текущую длину (`len`) и емкость (`cap`).

```
слайс []int{10, 20} (len=2, cap=3) в памяти (24 байта):
+-------------------+-------------------+-------------------+
| ptr (*array)      | len = 2 (int)     | cap = 3 (int)     |
| 8 байт            | 8 байт            | 8 байт            |
+--------+----------+-------------------+-------------------+
         |
         v указывает на базовый массив:
         [10, 20, 0]  (выделено памяти под 3 элемента)
```

### Мапы (map[K]V)
Мапа в Go — это указатель на структуру `hmap` (размером 8 байт на стеке). Сами данные лежат в бакетах (buckets). При передаче мапы в функцию копируется только этот 8-байтовый указатель, поэтому любые изменения мапы внутри функции видны снаружи.

```
Переменная map:
+-------------------+
| ptr (*hmap)       | ---> [ Структура hmap в куче ]
| 8 байт            |      - count (кол-во элементов)
+-------------------+      - buckets (указатель на бакеты)
                           - ...
```

### Интерфейсы (interface)
Пустой интерфейс `any` (`interface{}`) состоит из 16 байт: указатель на runtime-информацию о типе (`_type`) и указатель на сами данные (`data`).

```
Пустой интерфейс eface (16 байт):
+-------------------+-------------------+
| _type (*_type)    | data (unsafe.Ptr) |
| 8 байт            | 8 байт            |
+--------+----------+--------+----------+
         |                   |
         v                   v
   [Информация о типе]    [Значение (например, 42)]
```

## Именованные типы (Named Types) и псевдонимы (Type Aliases)

Go позволяет объявлять новые именованные типы и псевдонимы. Важно понимать разницу:

*   **Named Type** (Именованный тип): создаётся новый тип. Требует явного приведения.
    ```go
    type MyInt int // Создаётся новый тип MyInt
    var x int = 10
    var y MyInt = MyInt(x) // Требуется явное приведение типов
    ```
*   **Type Alias** (Псевдоним типа): просто новое имя для существующего типа. Приведение не нужно.
    ```go
    type MyAlias = int // MyAlias и int — это один и тот же тип
    var x int = 10
    var y MyAlias = x // Работает без приведения!
    ```
    *Примеры встроенных алиасов в Go:* `byte` (алиас для `uint8`) и `rune` (алиас для `int32`).

Подробнее о конверсиях между типами — в `05_conversions.md`.
