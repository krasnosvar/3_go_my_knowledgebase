# string, byte, rune

## string

```go
var s string       // "" (нулевое значение)
s = "Hello"
s = `многострочная
строка`
```

Внутреннее представление:

```go
type string struct {
    ptr *byte // указатель на данные
    len int   // длина в байтах
}
```

## Ключевые свойства

- Строки неизменяемы (immutable). Нельзя писать `s[0] = 'X'`.
- Хранятся в UTF-8.
- `len(s)` возвращает количество байтов, не символов.
- `s[i]` возвращает `byte`, не `rune`.
- Сравнение — лексикографическое.

```go
"a" < "b" // true
```

## byte и rune

- `byte` — alias для `uint8`, используется как "один байт строки".
- `rune` — alias для `int32`, представляет один Unicode code point.

```go
s := "Привет"
fmt.Println(len(s))         // 12 (байты)
fmt.Println(s[0])           // 208 (байт, не 'П')
fmt.Println([]rune(s)[0])   // 1055 (код 'П')

for i, r := range s {
    fmt.Printf("%d: %c\n", i, r) // i — индекс байта, r — rune
}
```

## Почему это важно

- Итерация через `range` даёт `rune` — безопасна для UTF-8.
- Итерация через `for i := 0; i < len(s); i++` даёт `byte` — можно попасть в середину многобайтового символа.
- Для изменения строки конвертируй в `[]rune` или `[]byte`, меняй и собери обратно через `string(...)`.

```go
runes := []rune("Привет")
runes[0] = 'п'
fmt.Println(string(runes)) // "привет"
```

## Конверсии

```go
b := []byte("hi") // копирует данные
s := string(b)    // копирует данные обратно
```

Повторная конверсия каждый раз копирует память — это важно для производительности в горячем цикле.
