# Типы данных — шпаргалка

Подробности и объяснения — в [01_theory/](./01_theory/). ⚠️ — частая ловушка.

## Карта типов

Подробно: [01_data_types_basics.md](./01_theory/01_data_types_basics.md).

| Категория | Тип | Размер (64-bit) | Zero value | `==` | При передаче копируется |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Логический | `bool` | 1 байт | `false` | да | значение |
| Целые | `int8`/`uint8` (`byte`) · `int16`/`uint16` · `int32` (`rune`)/`uint32` · `int64`/`uint64` | 1 · 2 · 4 · 8 байт | `0` | да | значение |
| Целые платформенные | `int`, `uint`, `uintptr` | 8 байт (4 на 32-bit) | `0` | да | значение |
| Float | `float32` · `float64` | 4 · 8 байт | `0` | да, ⚠️ неточно | значение |
| Комплексные | `complex64` · `complex128` | 8 · 16 байт | `(0+0i)` | да | значение |
| Строка | `string` | 16 байт (ptr + len) | `""` | да | заголовок, байты общие (immutable) |
| Массив | `[N]T` | `N * sizeof(T)` | массив нулей | если `T` сравним | весь массив |
| Структура | `struct` | сумма полей + padding | нулевые поля | если все поля сравнимы | вся структура |
| Указатель | `*T` | 8 байт | `nil` | да | адрес |
| Слайс | `[]T` | 24 байта (ptr + len + cap) | `nil` | только с `nil` | заголовок |
| Мапа | `map[K]V` | 8 байт (указатель) | `nil` | только с `nil` | указатель |
| Канал | `chan T` | 8 байт (указатель) | `nil` | да | указатель |
| Функция | `func(...)` | 8 байт | `nil` | только с `nil` | указатель |
| Интерфейс | `interface{...}`, `any` | 16 байт (type + data) | `nil` | да, ⚠️ panic, если динамический тип несравним | заголовок |

| Нужно сравнить | Чем |
| :--- | :--- |
| Два слайса | `slices.Equal(a, b)` (1.21+) |
| Две мапы | `maps.Equal(a, b)` (1.21+) |
| Произвольные структуры глубоко (тесты) | `reflect.DeepEqual(a, b)` |

## Числа

Подробно: [02_numeric_types.md](./01_theory/02_numeric_types.md).

| Тип | Диапазон |
| :--- | :--- |
| `int8` | −128 … 127 |
| `int16` | −32768 … 32767 |
| `int32` | −2147483648 … 2147483647 |
| `int64` | −9223372036854775808 … 9223372036854775807 |
| `uint8` / `uint16` / `uint32` | 0 … 255 / 65535 / 4294967295 |
| `uint64` | 0 … 18446744073709551615 |
| Константы границ | `math.MaxInt64`, `math.MinInt8`, `math.MaxUint32`, … |

| Факт | Детали |
| :--- | :--- |
| `int` и `int32` | разные типы: `int(x) == y` |
| Переполнение | wraparound без ошибки: `int8(127) + 1` → `-128` |
| Литерал `1.5` | по умолчанию `float64` |
| Сравнение float | `math.Abs(a-b) < 1e-9`, не `==` |
| Комплексные | `c := 1 + 2i`; `real(c)`, `imag(c)` |
| Деньги | целые в минимальных единицах (копейки) или `math/big`, не `float64` |

## string, byte, rune

Подробно: [03_string_byte_rune.md](./01_theory/03_string_byte_rune.md).

| Задача | Код | Результат для `s := "Привет"` |
| :--- | :--- | :--- |
| Длина в байтах | `len(s)` | `12` |
| Длина в символах | `utf8.RuneCountInString(s)` | `6` |
| i-й байт | `s[0]` | `208` (`byte`) |
| i-я руна | `[]rune(s)[0]` | `1055` (`'П'`) |
| Обход по символам | `for i, r := range s` | `i` — индекс байта, `r` — `rune` |
| Изменить символ | `r := []rune(s); r[0] = 'п'; s = string(r)` | `"привет"` |
| Многострочная raw-строка | `` `строка\nбез экранирования` `` | `\n` остаётся двумя символами |
| Сравнение | `"a" < "b"` | лексикографически, побайтово |

## Конверсии

Подробно: [05_conversions.md](./01_theory/05_conversions.md).

| Задача | Код |
| :--- | :--- |
| Число → число | `float64(i)`, `int64(x)`, `uint(i)` |
| Сужение (теряет старшие биты) | `int32(big)`, `uint16(u32)` |
| `string` ↔ `[]byte` (копия) | `b := []byte(s)`; `s := string(b)` |
| `string` → `[]rune` (копия) | `r := []rune(s)` |
| Число → текст | `strconv.Itoa(65)` → `"65"` |
| Текст → число | `n, err := strconv.Atoi("42")` |
| Код → символ | `string(rune(65))` → `"A"` |
| Новый тип ↔ базовый | `type UserID int`; `int(id)`, `UserID(n)` |
| Псевдоним | `type Alias = int` — тот же тип, конверсия не нужна |
| Обойти систему типов | `unsafe.Pointer` — только осознанно |

```go
package main

import (
	"fmt"
	"math"
	"strconv"
	"unicode/utf8"
)

type UserID int  // новый тип: нужна конверсия
type Alias = int // псевдоним: тот же тип

func main() {
	s := "Привет"
	fmt.Println(len(s), utf8.RuneCountInString(s), s[0], []rune(s)[0]) // 12 6 208 1055

	var z int8 = 127
	z++
	fmt.Println(z) // -128

	big := int64(1 << 40)
	fmt.Println(int32(big)) // 0 — старшие биты отброшены

	a1, b1 := 0.1, 0.2 // переменные: сложение в float64 в рантайме
	f := a1 + b1
	fmt.Println(f == 0.3, math.Abs(f-0.3) < 1e-9) // false true
	fmt.Println(0.1+0.2 == 0.3)                   // true: константы считаются точно

	fmt.Println(string(rune(65)), strconv.Itoa(65)) // A 65
	n, err := strconv.Atoi("42x")
	fmt.Println(n, err) // 0 strconv.Atoi: parsing "42x": invalid syntax

	var id UserID = 7
	var a Alias = 7
	fmt.Println(int(id)+a, real(1+2i), imag(1+2i)) // 14 1 2
}
```

## Нулевые значения и nil

Подробно: [04_zero_values.md](./01_theory/04_zero_values.md).

| Тип | Zero value | Безопасно | Опасно |
| :--- | :--- | :--- | :--- |
| `[]T` | `nil` | `len`, `cap`, `range`, `append` | `s[0]` → panic |
| `map[K]V` | `nil` | чтение (`m["x"]` → zero value), `len`, `range` | запись → panic |
| `chan T` | `nil` | выключить ветку `select` | send/recv блокируют навсегда |
| `*T` | `nil` | `p == nil` | `*p` → panic |
| `sync.Mutex`, `bytes.Buffer` | готовы к работе | `var mu sync.Mutex; mu.Lock()` | — |

## Выбор типа

Подробно: [06_use_cases.md](./01_theory/06_use_cases.md).

| Задача | Тип |
| :--- | :--- |
| Счётчик, индекс | `int` |
| ID в БД | `int64` |
| Флаги, бинарный формат фиксированного размера | `uint8` / `uint32` / `uint64` |
| Байт данных / символ | `byte` / `rune` |
| Динамический список / поиск по ключу / фиксированный размер | `[]T` / `map[K]V` / `[N]T` |
| Множество строк | `map[string]struct{}` |
| Ключ-пара в map | `map[[2]int]V` (массив сравним, слайс — нет) |
| «Значение не задано» vs ноль | `*int` |
| Может переполнить `int32` | `int64` или `big.Int` |

## Ловушки

- ⚠️ `len("Привет")` = 12 — байты, не символы.
- ⚠️ `s[i]` и `for i := 0; i < len(s); i++` дают байты — можно разрезать многобайтовый символ; для символов — `range` или `[]rune`.
- ⚠️ `string(65)` = `"A"`, не `"65"` (`go vet` предупреждает) — для чисел `strconv.Itoa`.
- ⚠️ Сужающее приведение (`int32(int64(1 << 40))` → `0`) молча теряет биты.
- ⚠️ `a + b == 0.3` для `float64`-переменных `0.1` и `0.2` → `false`; при этом константное `0.1+0.2 == 0.3` → `true` (константы считаются точно).
- ⚠️ `[]byte(s)` / `string(b)` копируют каждый раз — выносить из горячего цикла.
- ⚠️ Слайс, мапа, функция не могут быть ключом map и не сравниваются `==` (кроме `nil`).
- ⚠️ `struct{ A int }` и `struct{ B int }` — разные типы, хоть layout одинаков.
- ⚠️ Интерфейс с nil-указателем внутри `!= nil` — см. [06_pointers](../06_pointers/CHEATSHEET.md#nil-и-интерфейсы).
