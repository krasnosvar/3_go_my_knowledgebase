# Printf verbs (глаголы форматирования)

## Универсальные

| Verb | Для чего | Пример |
|---|---|---|
| `%v` | значение по умолчанию | `fmt.Printf("%v\n", u)` |
| `%+v` | struct с именами полей | `{ID:1 Name:den}` |
| `%#v` | Go-синтаксис | `main.User{ID:1, Name:"den"}` |
| `%T` | тип значения | `main.User` |
| `%%` | литеральный % | `50%%` |

## Числа

| Verb | Для чего |
|---|---|
| `%d` | десятичное целое |
| `%b` | двоичное |
| `%o` | восьмеричное |
| `%x` / `%X` | шестнадцатеричное (строчные/заглавные) |
| `%c` | rune как символ |
| `%U` | Unicode: `U+0041` |
| `%f` / `%F` | float |
| `%e` / `%E` | научная нотация |
| `%g` / `%G` | компактный float |

## Строки и байты

| Verb | Для чего |
|---|---|
| `%s` | строка |
| `%q` | строка в Go-кавычках (экранированная) |
| `%x` / `%X` | hex-представление байтов |

## Указатели

`%p` — адрес в формате `0xADDR`.

## Ширина и точность

```go
fmt.Printf("%5d\n", 42)   // "   42" (ширина 5)
fmt.Printf("%-5d|\n", 42) // "42   |" (выравнивание влево)
fmt.Printf("%05d\n", 42)  // "00042"
fmt.Printf("%.2f\n", 3.14159) // "3.14"
fmt.Printf("%8.2f\n", 3.14)   // "    3.14"
fmt.Printf("%10.5s\n", "hello world") // "     hello" (макс 5 символов)
```

## Порядок аргументов

По умолчанию аргументы берутся по порядку. Можно обращаться повторно через индекс `[n]`:

```go
fmt.Printf("%[2]d %[1]d\n", 1, 2) // "2 1"
fmt.Printf("%[1]d + %[1]d = %[2]d\n", 2, 4) // "2 + 2 = 4"
```

## Советы

- Для логов всегда `%v` + `%T` бывает полезно (видно что за тип).
- `%q` удобен при отладке: видно точные кавычки и экранирование.
- Для длинных строк форматирования легче держать именованные константы.
