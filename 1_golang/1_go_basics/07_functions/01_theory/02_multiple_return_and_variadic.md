# Multiple return и variadic

## Множественные возвращаемые значения

Одна из ключевых особенностей Go — функция может возвращать несколько значений.

```go
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, fmt.Errorf("деление на ноль")
    }
    return a / b, nil
}

result, err := divide(10, 2)
if err != nil {
    return err
}
```

По соглашению последний результат — `error`, если функция может упасть.

## Именованные возвращаемые значения

Имена объявляются в сигнатуре и инициализируются нулевыми значениями:

```go
func split(sum int) (x, y int) {
    x = sum * 4 / 9
    y = sum - x
    return // голый return возвращает x и y
}
```

Удобно для коротких функций, в длинных ухудшает читаемость — называть именованный возврат стоит осознанно.

## Variadic (переменное число аргументов)

`...T` собирает аргументы в слайс `[]T`.

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}

sum(1, 2, 3)       // 6
sum(1, 2, 3, 4, 5) // 15
```

### Передача слайса в variadic

Если уже есть слайс — разворачиваем оператором `...`:

```go
numbers := []int{1, 2, 3, 4}
sum(numbers...) // 10
```

Иначе компилятор ругнётся: `cannot use numbers (type []int) as type int`.

## Ограничения

- Только один variadic-параметр, и он обязан быть последним.
- Внутри функции `nums` — обычный слайс: нельзя различить вызовы `sum()` и `sum([]int{}...)`.
