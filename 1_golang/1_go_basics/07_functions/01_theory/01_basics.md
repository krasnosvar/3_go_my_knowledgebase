# Functions: основы

Функции — основные строительные блоки Go-программы.

## Базовое объявление

```go
// полный вид
func add(x int, y int) int {
    return x + y
}

// если параметры одного типа — сокращение
func add(x, y int) int {
    return x + y
}

// без возвращаемого значения
func printMessage(msg string) {
    fmt.Println(msg)
}

// без параметров
func sayHello() {
    fmt.Println("hello")
}
```

## Передача аргументов

В Go **все аргументы передаются по значению** (копия). Чтобы функция могла изменить внешнюю переменную — передавай указатель.

```go
func modifyValue(x int) {
    x = 100 // изменит только локальную копию
}

func modifyPointer(x *int) {
    *x = 100 // изменит оригинал
}

a := 10
modifyValue(a)   // a == 10
modifyPointer(&a) // a == 100
```

### Ссылочные типы

Слайсы, map и каналы — это ссылочные заголовки, копирование которых не копирует базовые данные. Правки «внутри» слайса/map видны снаружи.

```go
func modifySlice(s []int) {
    s[0] = 999
}
nums := []int{1, 2, 3}
modifySlice(nums) // nums == [999 2 3]
```

## Базовые правила

- Функция должна решать одну задачу — так её проще переиспользовать и тестировать.
- Публичные функции начинаются с заглавной буквы, приватные — со строчной.
- `error` — всегда последний возвращаемый аргумент, если функция может упасть.
- Если функция принимает `context.Context`, он идёт первым аргументом.
