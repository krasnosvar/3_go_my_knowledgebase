# Функции первого класса (First-Class Functions) в Go

В программировании термин «объекты первого класса» (first-class citizens) означает, что сущности (в данном случае функции) можно использовать так же, как обычные данные (числа или строки).

В Go это даёт огромную гибкость. Вот что конкретно можно делать с функциями:

## 1. Присвоить функцию переменной

Функцию можно сохранить в переменной и вызывать через неё.

```go
func main() {
    // присваиваем анонимную функцию переменной greet
    greet := func(name string) {
        fmt.Println("Hello,", name)
    }

    greet("Alexey") // вызов функции через переменную
}
```

## 2. Передать функцию как аргумент

Функции могут принимать другие функции в качестве параметров. Это основа гибкого кода и колбэков (callbacks).

```go
func compute(x, y int, operation func(int, int) int) int {
    return operation(x, y)
}

func main() {
    sum := func(a, b int) int { return a + b }

    // передаём функцию sum в функцию compute
    result := compute(5, 10, sum)
    fmt.Println(result) // 15
}
```

## 3. Вернуть функцию из другой функции

Функция может создавать и возвращать новую функцию. Это позволяет создавать замыкания (см. [04_closures.md](./04_closures.md)).

```go
func multiplier(factor int) func(int) int {
    return func(n int) int {
        return n * factor
    }
}

func main() {
    double := multiplier(2) // теперь double — функция, умножающая на 2
    fmt.Println(double(5))  // 10
}
```

## Почему это важно

Поскольку функции в Go — «объекты первого класса», становится возможным следующее:

### Гибкая логика
Можно менять поведение программы «на лету», передавая разные функции.

### Замыкания
Функции могут «запоминать» окружение, в котором были созданы.

### Декораторы и middleware
Часто применяются в веб-разработке на Go (например, для проверки авторизации перед выполнением основного кода).
