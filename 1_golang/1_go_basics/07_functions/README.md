# Тема 07. Функции (Functions)

Этот раздел посвящен изучению функций в Go, замыканий (closures), отложенных вызовов `defer`, обработки паник `panic/recover` и дженериков (обобщенного программирования).

## 📋 Пререквизиты

*   Пройдена предыдущая тема: [06_pointers](../06_pointers/).

> ⏩ **Забегание вперёд.** Некоторые примеры и упражнения используют конструкции из следующих тем:
> *   `08_generic_min` и теория [05_generics.md](./01_theory/05_generics.md) — дженерики; ограничения (constraints) — это интерфейсы, поэтому полная тема — в [2_oop/05_generics](../../2_oop/05_generics/) после [2_oop/02_interfaces](../../2_oop/02_interfaces/).
> *   `07_error_wrapper` использует `error`, `panic`/`recover` — подробно в [12_errors](../12_errors/).
> *   Пример `02_system_infrastructure` запускает горутину — подробно в [3_concurrency/01_goroutines](../../3_concurrency/01_goroutines/).

## 🗂 Структура раздела

*   **[01_theory/](./01_theory/)** — теория:
    *   [01_basics.md](./01_theory/01_basics.md) — **основы функций: объявление и сигнатуры, передача аргументов по значению и по указателю, поведение ссылочных типов (слайсы, map, каналы), базовые правила именования и порядка аргументов**.
    *   [02_multiple_return_and_variadic.md](./01_theory/02_multiple_return_and_variadic.md) — множественные возвращаемые значения, именованный возврат и «голый» `return`, variadic-параметры (`...T`) и передача слайса через `...`.
    *   [03_first_class_functions.md](./01_theory/03_first_class_functions.md) — функции первого класса: присваивание переменной, передача аргументом, возврат функции из функции, колбэки и декораторы.
    *   [04_closures.md](./01_theory/04_closures.md) — замыкания: захват переменных по ссылке, escape analysis и утечка в кучу (heap escape), жизненный цикл захваченных переменных и GC, изоляция состояния, частые ошибки (shadowing).
    *   [05_generics.md](./01_theory/05_generics.md) — подробный учебник по дженерикам (параметры типов, ограничения, аппроксимация `~`, интерфейс `comparable` и производительность GCShape).
    *   [06_defer_panic_recover.md](./01_theory/06_defer_panic_recover.md) — **три правила `defer` (немедленное вычисление аргументов, порядок LIFO, доступ к именованному возврату), механика `panic`/`recover` и разворачивание стека, почему `recover()` работает только в `defer`, и случаи, когда `defer` не выполнится**.
    *   [07_use_cases.md](./01_theory/07_use_cases.md) — практические сценарии: dispatch команд CLI, HTTP middleware, декораторы retry/timeout, подмена поведения в тестах, инкапсуляция состояния через замыкания.
*   **[02_examples/](./02_examples/)** — практические примеры:
    *   [01_cli_utilities](./02_examples/01_cli_utilities/main.go) — оборачивание команд CLI в middleware-функции первого класса для логирования выполнения и замера времени.
    *   [02_system_infrastructure](./02_examples/02_system_infrastructure/main.go) — безопасный запуск фоновых воркеров с предотвращением падения приложения через перехват паник (`recover`).
    *   [03_product_backend](./02_examples/03_product_backend/main.go) — **реализация middleware-авторизации HTTP-запросов с использованием замыканий**.
*   **[03_exercises/](./03_exercises/)** — интерактивные задачи для самопроверки с автопроверками `PASS`/`FAIL`:
    *   `01_basic_declaration` — объявление функции форматирования строки приветствия.
    *   `02_multiple_return` — возвращение частного и остатка при делении с проверкой на ноль.
    *   `03_variadic` — суммирование переменного числа аргументов.
    *   `04_first_class` — применение функции-операции к каждому элементу слайса.
    *   `05_closure_counter` — создание счетчика с инкрементируемым шагом через замыкание.
    *   `06_defer_order` — модификация именованного возвращаемого значения внутри `defer`.
    *   `07_error_wrapper` — безопасный запуск функции с перехватом паник и конвертацией их в `error`.
    *   `08_generic_min` — **написание обобщенной функции `Min` с ограничением `cmp.Ordered`**.
*   **[04_exercises_answers/](./04_exercises_answers/)** — эталонные решения.

## 🚀 Как проходить тему

1. Начните с основ: [01_basics.md](./01_theory/01_basics.md), затем изучите остальные файлы теории по порядку.
2. Запустите и изучите примеры из папки `02_examples/` через `go run`:
   ```bash
   go run ./02_examples/02_system_infrastructure/main.go
   ```
3. Выполните задачи в `03_exercises/`. Запустите встроенный тест для самопроверки:
   ```bash
   go run ./03_exercises/05_closure_counter/main.go
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.
