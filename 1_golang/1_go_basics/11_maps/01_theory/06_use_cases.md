# Практические применения мап

Краткий обзор типовых сценариев использования мап, разобранных в этой главе. Подробные реализации — в `02_examples/` и `03_exercises/`.

## Command Registry (диспетчеризация команд)

Мапа `map[string]func(...)` позволяет сопоставлять имя команды с обработчиком и вызывать нужный за `O(1)` вместо длинной цепочки `switch`/`if`. Типичное применение — разбор консольных команд CLI-утилиты.

## Множество (Set) на `map[K]struct{}`

Мапа со значением `struct{}` реализует множество: важен только факт присутствия ключа, а значение не занимает памяти (пустая структура имеет нулевой размер). Проверка принадлежности — через comma-ok.

## Потокобезопасное хранилище

Мапа под защитой `sync.RWMutex` служит основой для конкурентных хранилищ: кэша, счётчика посещений, хранилища пользовательских сессий. Чтения выполняются под `RLock`, записи — под `Lock` (см. `05_concurrency.md`).

## Контроль потребления памяти

При работе с большими мапами, из которых массово удаляются ключи, применяют ручную усадку пересозданием, чтобы вернуть память ОС (см. `04_memory_delete.md`).

## Сортировка содержимого мапы

Так как порядок обхода мапы случаен, для упорядоченного вывода ключи извлекают в срез, сортируют его и затем обходят мапу по отсортированному срезу ключей.

## LRU-кэш

Мапа в связке с двусвязным списком (`container/list`) даёт LRU-кэш: мапа обеспечивает доступ к элементу за `O(1)`, список хранит порядок использования для вытеснения давно не запрашиваемых элементов.
