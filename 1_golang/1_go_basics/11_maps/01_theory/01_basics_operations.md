# Хеш-таблицы (Maps): основы и операции

Хеш-таблица в Go объявляется как `map[KeyType]ValueType`. Она обеспечивает поиск, запись и удаление по ключу за амортизированное `O(1)`.

## Объявление и инициализация

Мапу необходимо инициализировать перед записью с помощью `make(...)` или литерала, иначе запись в неё вызовет **панику (nil map)**.

```go
// nil map: чтение допустимо (вернёт нулевое значение), запись вызовет панику
var m map[string]int
_ = m["x"]      // OK: вернёт 0
// m["x"] = 1   // panic: assignment to entry in nil map

// Инициализация через make
m1 := make(map[string]int)

// Инициализация литералом
m2 := map[string]int{
    "alice": 20,
    "bob":   30,
}
```

## Запись и чтение

```go
m := make(map[string]int)
m["alice"] = 20        // запись
age := m["alice"]      // чтение, age == 20
missing := m["nobody"] // чтение отсутствующего ключа -> нулевое значение (0)
```

## Проверка существования ключа (comma-ok)

Чтение отсутствующего ключа возвращает нулевое значение типа, поэтому по одному значению нельзя отличить «нет ключа» от «значение равно нулю». Для этого используется comma-ok паттерн:

```go
val, ok := m[key]
if ok {
    // ключ существует, val — его значение
}
```

## Удаление элемента

Удаление выполняется через встроенную функцию `delete`:

```go
delete(m, "alice")
```

`delete` безопасно вызывать даже для несуществующего ключа — ошибки не будет.

## Случайный порядок обхода

Порядок обхода мапы в цикле `for range` **всегда случайный** — не закладывайтесь на него. Подробнее о том, как и зачем это реализовано, см. `02_internals_hmap.md`.

```go
for k, v := range m {
    // порядок k, v непредсказуем
}
```

> ⚠️ Частый вопрос на собеседовании: чем отличается чтение отсутствующего ключа от ключа с нулевым значением и как это различить? Ответ — comma-ok паттерн.
