# Неадресуемость значений мапы

Вы не можете получить адрес элемента мапы или напрямую изменить поле структуры, лежащей в мапе:

```go
type User struct{ Age int }
m := make(map[string]User)
m["alice"] = User{Age: 20}

// ОШИБКА КОМПИЛЯЦИИ: cannot assign to struct field m["alice"].Age in map
m["alice"].Age = 21
// ОШИБКА КОМПИЛЯЦИИ: cannot take the address of m["alice"]
ptr := &m["alice"]
```

## Почему?

Мапа динамически перемещает бакеты в памяти при увеличении емкости. Если бы Go разрешил хранить указатели на элементы внутри мапы, эти указатели стали бы невалидными (висячими указателями) сразу после рехэшинга.

## Как решить

1. Хранить указатели на структуры: `map[string]*User`.
2. Копировать структуру, менять поле и записывать обратно:
   ```go
   u := m["alice"]
   u.Age = 21
   m["alice"] = u
   ```

> ⚠️ Частый вопрос на собеседовании: почему `m["alice"].Age = 21` не компилируется и как это обойти? Ответ — неадресуемость значений мапы из-за рехэшинга; решается указателями или копированием структуры.
