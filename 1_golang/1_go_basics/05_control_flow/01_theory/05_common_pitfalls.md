# Частые ошибки control flow

## 1. Бесконечный цикл без условия выхода

```go
// плохо: некому вызвать break
for {
    work()
}
```

Всегда должен быть путь наружу: `return`, `break`, `ctx.Done()`, канал-сигнал.

## 2. break внутри select, но нужен был выход из for

`break` в `select` выходит только из `select`. Для выхода из внешнего `for` — только через label:

```go
Loop:
for {
    select {
    case <-done:
        break Loop
    }
}
```

## 3. Путаница индекса и значения в range

```go
for i := range nums { // i — это индекс, а не значение
    fmt.Println(i)
}
```

Если нужно именно значение — бери `_, v := range nums`.

## 4. Модификация значения через переменную цикла

```go
for _, v := range items {
    v.Done = true // меняется копия, исходный слайс не обновится
}
```

Для in-place правок используй индекс: `items[i].Done = true`.

## 5. Пустой default в switch

`default: // do nothing` не помогает читаемости. Если нет реального действия — лучше убрать его совсем.

## 6. if/else лестница там, где уместен switch

Если веток больше 3 и все сравнивают одну переменную — `switch` читаемее и компактнее, чем длинная цепочка `if/else if`.
