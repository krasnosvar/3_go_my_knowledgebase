# if / else

Базовое условное ветвление. В Go нет тернарного оператора — `a if cond else b` записывается через полноценный `if`.

## Базовый синтаксис

```go
if x > 0 {
    fmt.Println("positive")
} else if x == 0 {
    fmt.Println("zero")
} else {
    fmt.Println("negative")
}
```

Фигурные скобки `{ }` обязательны даже для одной строки.

## if с короткой инициализацией

Переменная видна только внутри `if/else` веток:

```go
if v, err := parse(s); err == nil {
    use(v)
} else {
    log.Println(err)
}
```

Это идиоматический способ проверки ошибок и наличия ключа в map.

## Особенности

- Условие должно быть `bool` — никаких неявных преобразований (`if x` для `int` не работает).
- Нельзя присваивать в условии: `if x = 1` — ошибка компиляции.
- Ранний `return` часто чище, чем глубокая вложенность `if/else`.

```go
// плохо
if ok {
    if v > 0 {
        // ...
    }
}

// хорошо
if !ok {
    return
}
if v <= 0 {
    return
}
```
