# Все о цикле for в Go

В языке Go `for` — это единственный цикл. Он заменяет собой `while`, `do-while` и классические итераторы.

## 1. Классический for (Три составные части)

Используется, когда нужно точно контролировать индексы или идти "навстречу" (как в палиндроме).

```go
// Инициализация; Условие; Инкремент
for i := 0; i < 10; i++ {
    fmt.Println(i)
}

// С двумя указателями (техника для разворота слайса/строки)
for x, y := 0, 10; x < y; x, y = x+1, y-1 {
    fmt.Printf("x: %d, y: %d\n", x, y)
}
```

## 2. for как while

Если оставить только условие, цикл работает, пока оно истинно.

```go
n := 1
for n < 100 {
    n *= 2
}
```

## 3. Бесконечный цикл

Аналог `while(true)`. Часто используется в связке с `select` или для ожидания событий.

```go
for {
    if someCondition {
        break // выход из цикла
    }
}
```

## 4. for range (Итератор)

Лучший способ перебора коллекций.

| Коллекция      | Первое значение    | Второе значение    |
|----------------|--------------------|--------------------|
| Слайс/Массив   | Индекс (int)       | Значение элемента  |
| Строка         | Индекс байта (int) | Руна (rune)        |
| Map            | Ключ               | Значение           |
| Канал (chan)   | Значение из канала | (нет)              |

```go
words := []string{"Go", "is", "awesome"}
for i, word := range words {
    fmt.Printf("Индекс: %d, Слово: %s\n", i, word)
}

// Если индекс не нужен, используй заглушку "_"
for _, word := range words {
    fmt.Println(word)
}
```

## 5. Управление циклом

- **break**: немедленный выход из цикла.
- **continue**: пропуск текущей итерации и переход к следующей.
- **Метки (Labels)**: позволяют прервать внешний цикл из внутреннего.

```go
OuterLoop:
for i := 0; i < 3; i++ {
    for j := 0; j < 3; j++ {
        if i+j == 4 {
            break OuterLoop // Выйдет сразу из обоих циклов
        }
    }
}
```

## 6. Важные особенности

### Работа со строками

При `range` по строке Go возвращает руны (UTF-8), но индексы соответствуют байтам. Для корректной работы с кириллицей по индексам всегда приводи строку к слайсу рун:

```go
runes := []rune("Привет") // Каждая буква теперь занимает 1 индекс
```

### Переменные цикла и Горутины

Начиная с Go 1.22, переменная цикла создается заново на каждой итерации. Это делает безопасным использование её внутри замыканий:

```go
for _, n := range []int{1, 2, 3} {
    go func() {
        fmt.Println(n) // В Go 1.22+ выведет 1, 2, 3 в случайном порядке
    }()
}
```

#### Как это было до Go 1.22

До Go 1.22 переменные `for range` создавались **один раз** на весь цикл и перезаписывались на каждой итерации. Это приводило к классическому багу — все указатели ссылались на одну и ту же переменную:

```go
// БАГ в Go < 1.22:
out := make([]*int, 0, 3)
for _, v := range []int{1, 2, 3} {
    out = append(out, &v) // сохраняли адрес ОДНОЙ И ТОЙ ЖЕ переменной v
}
// В итоге все элементы out указывали на последнее значение: [3, 3, 3]
```

Тот же баг возникал при запуске горутин внутри цикла с использованием переменной цикла. В старых кодовых базах для обхода этой проблемы писали `v := v` внутри тела цикла, создавая новую переменную вручную. В Go 1.22+ код выше отработает корректно и вернет `[1, 2, 3]`.

### Производительность range по большим массивам

При обходе массива вида `for i, value := range array` Go **копирует** каждый элемент в переменную `value`. Если массив состоит из больших структур, это может заметно снизить производительность. Способы избежать лишнего копирования:

- range по указателю на массив: `for i, v := range &array`;
- обход только по индексу с обращением по нему: `for i := range array { use(array[i]) }` (копирования значения не происходит);
- использовать слайс вместо массива (в range попадает только заголовок слайса, а не все данные).
