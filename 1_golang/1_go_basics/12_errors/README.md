# Тема 12. Обработка ошибок (Errors)

Этот раздел посвящен изучению идиоматической обработки ошибок в Go: механизму обертывания ошибок (Wrapping), функциям `errors.Is` и `errors.As`, написанию кастомных структур ошибок и обходу ловушки типизированного `nil` в интерфейсе.

## 📋 Пререквизиты

*   Пройдена предыдущая тема: [11_maps](../11_maps/).

> ⏩ **Забегание вперёд.** Некоторые примеры и упражнения используют конструкции из следующих тем:
> *   `error` — это интерфейс; `errors.As` и собственные типы ошибок опираются на интерфейсы и методы — подробно в [2_oop/02_interfaces](../../2_oop/02_interfaces/).

## 🗂 Структура раздела

*   **[01_theory/](./01_theory/)** — теория:
    *   [01_basics.md](./01_theory/01_basics.md) — **вводный файл: интерфейс `error`, создание ошибок через `errors.New` и `fmt.Errorf`, стандартный паттерн проверки (early return), освобождение ресурсов через `defer`**.
    *   [02_wrapping_is_as.md](./01_theory/02_wrapping_is_as.md) — обертывание через `%w`, разбор цепочки, разница между `errors.Is` (sentinel) и `errors.As` (типы), `errors.Join`.
    *   [03_custom_errors.md](./01_theory/03_custom_errors.md) — свои типы ошибок: sentinel и типизированные, метод `Unwrap`, ловушка типизированного `nil` (typed nil gotcha).
    *   [04_panic_recover_boundary.md](./01_theory/04_panic_recover_boundary.md) — когда `panic`, а когда `error`; `recover` в `defer` на границе; поведение между горутинами.
    *   [05_patterns.md](./01_theory/05_patterns.md) — идиоматические паттерны: early return, контекстное оборачивание, sentinel+Is, тип+As, «не глотать» ошибку.
    *   [06_use_cases.md](./01_theory/06_use_cases.md) — практические сценарии: валидация, внешние API, ФС/БД, retry, `context.Canceled`, пользовательские сообщения.
*   **[02_examples/](./02_examples/)** — практические примеры:
    *   [01_cli_utilities](./02_examples/01_cli_utilities/main.go) — каскадная обработка ошибок с обертыванием при чтении файлов конфигураций и выводом полной трассировочной цепочки.
    *   [02_system_infrastructure](./02_examples/02_system_infrastructure/main.go) — симуляция клиента с логикой повторных попыток (Retry) при обнаружении сетевых таймаутов через `errors.Is`.
    *   [03_product_backend](./02_examples/03_product_backend/main.go) — **извлечение кастомной ошибки `APIError` через `errors.As` в HTTP-обработчике для автоматического формирования JSON-ответа со статус-кодом**.
*   **[03_exercises/](./03_exercises/)** — интерактивные задачи для самопроверки с автопроверками `PASS`/`FAIL`:
    *   `01_basic_error` — создание и возврат базовой ошибки при некорректных аргументах.
    *   `02_wrap` — обертывание ошибки с добавлением контекста выполнения.
    *   `03_is` — рекурсивная проверка наличия sentinel error в цепочке ошибок.
    *   `04_as` — поиск и извлечение полей кастомной ошибки `ValidationError` из цепочки.
    *   `05_custom_type` — описание кастомного типа ошибки, реализующего интерфейс `error` с pointer receiver.
    *   `06_defer_close` — **идиоматическая обработка ошибок закрытия файлов/ресурсов в defer с обновлением именованного возврата**.
    *   `07_multi_step` — многоэтапное обертывание ошибок по стеку вызовов.
    *   `08_retry` — **обнаружение и исправление ловушки типизированного nil (typed nil error) в интерфейсах**.
*   **[04_exercises_answers/](./04_exercises_answers/)** — эталонные решения.

## 🚀 Как проходить тему

1. Прочитайте теорию по порядку, начиная с [01_basics.md](./01_theory/01_basics.md).
2. Запустите и изучите примеры из папки `02_examples/` через `go run`:
   ```bash
   go run ./02_examples/02_system_infrastructure/main.go
   ```
3. Выполните задачи в `03_exercises/`. Запустите встроенный тест для самопроверки:
   ```bash
   go run ./03_exercises/08_retry/main.go
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.
