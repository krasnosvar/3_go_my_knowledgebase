# Тэги структур (Struct Tags)

Тэги структур — это метаданные полей, считываемые во время выполнения с помощью рефлексии (пакет `reflect`). Чаще всего они используются для десериализации JSON/XML или для работы с ORM:

```go
type User struct {
    ID   int    `json:"id" db:"user_id"`
    Name string `json:"name"`
}
```

## Под капотом

Пакеты вроде `encoding/json` читают тэги и сопоставляют ключи JSON с полями структуры. Если тэг не указан, JSON-парсер ищет поля по их именам (без учёта регистра).

Один тэг может содержать несколько пар «ключ-значение» для разных потребителей (например, `json:"id" db:"user_id"`) — каждый пакет читает только свой ключ.

> ⚠️ Частый вопрос на собеседовании: как рефлексия узнаёт про тэг? Тэг — это обычная строка, привязанная к полю; `reflect` предоставляет доступ к ней через `StructField.Tag`, а конкретные пакеты (`encoding/json` и др.) парсят её по своему формату.
