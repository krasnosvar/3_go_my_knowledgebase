# Практические применения

Ниже — как темы из этой главы применяются на практике. Разбор рабочего кода см. в каталоге `02_examples/`.

## Конфигурация через встраивание

Встраивание удобно для конфигураций: общие поля выносятся в базовую структуру, а конкретные конфиги её встраивают и при необходимости переопределяют поля (пример `01_cli_utilities` — `BaseConfig` внутри `ServerConfig`).

## Оптимизация памяти через порядок полей

Когда структур в программе миллионы, порядок полей напрямую влияет на потребление памяти. Замер `unsafe.Sizeof` показывает разницу между неоптимальным и оптимальным расположением (24 против 16 байт) — см. `02_system_infrastructure`.

## Сериализация в JSON через тэги

Тэги задают соответствие полей структуры ключам JSON и управляют маршалингом/анмаршалингом. Флаг `omitempty` позволяет опускать пустые поля в выходном JSON — см. `03_product_backend`.

## Проектирование под нулевое значение

Структуру полезно проектировать так, чтобы её нулевое значение уже было пригодно к использованию (например, конфигурация форматирования логов с разумными значениями по умолчанию) — это избавляет от лишних конструкторов и проверок.

## Копия против указателя

Передача структуры по значению создаёт независимую копию: изменения внутри функции не затрагивают оригинал. Чтобы изменять исходную структуру, её передают по указателю. Это же различие лежит в основе выбора между value- и pointer-ресивером у методов.
