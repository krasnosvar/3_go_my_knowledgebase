# Объявление и инициализация структур

Структура (`struct`) в Go — это именованный набор полей. Классов в языке нет, поэтому структуры служат основой для объектно-ориентированного программирования через композицию.

## Экспортируемые и приватные поля

Как и для всех идентификаторов в Go, видимость поля определяется регистром первой буквы:

*   поле с **заглавной** буквы (`Name`) — экспортируемое, доступно из других пакетов;
*   поле со **строчной** буквы (`name`) — приватное, доступно только внутри своего пакета.

## Создание экземпляра (идиоматический способ)

Всегда инициализируйте структуры через указание имён полей. Это убережёт код от поломок при добавлении новых полей:

```go
p := Person{
    Name: "Алексей",
    Age:  30, // запятая в конце обязательна!
}
```

Позиционная инициализация (`Person{"Иван", 25}`) не рекомендуется: при добавлении или перестановке полей она молча ломается или перестаёт компилироваться.

## Нулевое значение (zero value)

Если создать структуру без инициализации полей, каждое поле получит нулевое значение своего типа (`0` для чисел, `""` для строк, `false` для `bool`, `nil` для указателей, срезов и мап). Структуру полезно проектировать так, чтобы её нулевое значение было сразу пригодно к использованию.

## Анонимные структуры

Анонимная структура объявляется без предварительного именованного типа — прямо в месте использования. Такие структуры часто применяются при тестировании (табличные тесты) или при разборе JSON, когда отдельный тип заводить незачем:

```go
point := struct {
    X, Y int
}{X: 1, Y: 2}
```

## Сравнимость структур

Структуры можно сравнивать операторами `==` и `!=`, если **все их поля сравнимы**.

*   *Сравнимые типы*: `int`, `string`, `bool`, `float`, указатели, каналы, массивы.
*   *Несравнимые типы*: `slice`, `map`, `func` — их наличие в структуре делает саму структуру несравнимой.

> ⚠️ Частый вопрос на собеседовании: почему структуру со срезом или мапой нельзя сравнить через `==`? Потому что для этих типов оператор `==` не определён, и он «заражает» несравнимостью всю структуру.
