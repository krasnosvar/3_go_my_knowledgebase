# Структуры — шпаргалка

Подробности и объяснения — в [01_theory/](./01_theory/). ⚠️ — частая ловушка.

## Объявление и инициализация

Подробно: [01_declaration_and_init.md](./01_theory/01_declaration_and_init.md).

| Задача | Код |
| :--- | :--- |
| Тип | `type Person struct { Name string; Age int }` |
| Литерал с именами полей (идиома) | `p := Person{Name: "Алексей", Age: 30}` — запятая после последнего поля в многострочном литерале обязательна |
| Позиционный литерал (не рекомендуется) | `Person{"Иван", 25}` — ломается при добавлении/перестановке полей |
| Нулевое значение | `var p Person` → `{Name:"" Age:0}` |
| Указатель на новую структуру | `p := &Person{Name: "A"}` или `new(Person)` |
| Доступ через указатель | `p.Name` (автоматически `(*p).Name`) |
| Анонимная структура | `pt := struct{ X, Y int }{X: 1, Y: 2}` — табличные тесты, разовый JSON |
| Видимость поля | `Name` — экспортируется, `name` — только внутри пакета |
| Печать с именами полей | `fmt.Printf("%+v\n", p)` → `{Name:Алексей Age:30}` |

| Нулевые значения полей | |
| :--- | :--- |
| числа | `0` |
| `string` | `""` |
| `bool` | `false` |
| указатель, слайс, мапа, канал, функция, интерфейс | `nil` |
| вложенная структура | структура из нулевых полей |

## Сравнимость

| Поля структуры | `==` / ключ мапы |
| :--- | :--- |
| только `int`, `string`, `bool`, `float`, указатели, каналы, массивы сравнимых, интерфейсы | можно |
| есть `slice`, `map` или `func` | не компилируется — сравнивать вручную или `reflect.DeepEqual` |

## Встраивание (embedding)

Подробно: [02_embedding.md](./01_theory/02_embedding.md); глубже — [2_oop/03_embedding](../../2_oop/03_embedding/).

| Задача | Код |
| :--- | :--- |
| Встроить тип | `type Admin struct { User; Role string }` |
| Инициализация | `Admin{User: User{Name: "Иван"}, Role: "Super"}` |
| Продвинутое поле / метод | `a.Name`, `a.Hello()` ≡ `a.User.Name`, `a.User.Hello()` |
| Конфликт имён | внешнее поле затеняет встроенное; встроенное — `a.User.Name` |
| Отношение | композиция: `Admin` — не `User`, передать `Admin` как `User` нельзя |

## Тэги

Подробно: [03_tags.md](./01_theory/03_tags.md).

| Задача | Код |
| :--- | :--- |
| Тэги для нескольких пакетов | ``ID int `json:"id" db:"user_id"` `` — пары через пробел |
| Пропустить пустое при маршалинге | ``Name string `json:"name,omitempty"` `` |
| Не сериализовать | ``Secret string `json:"-"` `` |
| Прочитать тэг | `f, _ := reflect.TypeOf(User{}).FieldByName("ID"); f.Tag.Get("db")` → `user_id` |
| Без тэга | `encoding/json` берёт имя поля; при декодировании сопоставляет без учёта регистра |

## Выравнивание и размер

Подробно: [04_memory_alignment.md](./01_theory/04_memory_alignment.md).

| Структура (64 бит) | `unsafe.Sizeof` |
| :--- | :--- |
| `{a bool; b int64; c bool}` | 24 (по 7 байт padding после каждого `bool`) |
| `{b int64; a bool; c bool}` | 16 (два `bool` в одном слове) |
| `struct{}` | 0 |

| Правило | |
| :--- | :--- |
| Поле начинается со смещения, кратного своему выравниванию | отсюда padding между полями |
| Размер кратен выравниванию самого крупного поля | отсюда padding в конце |
| Порядок полей | по убыванию размера: `int64`/указатели → `int32` → `bool`/`byte` |
| Где важно | миллионы экземпляров; иначе порядок — для читаемости |

## Use-cases

Подробно: [05_use_cases.md](./01_theory/05_use_cases.md).

| Задача | Приём |
| :--- | :--- |
| Общие поля конфигов | встроить `BaseConfig` в `ServerConfig` |
| Экономия памяти | переставить поля, проверить `unsafe.Sizeof` |
| JSON API | тэги `json:"..."` + `omitempty` |
| Готовность «из коробки» | проектировать нулевое значение рабочим (как `sync.Mutex`, `bytes.Buffer`) |
| Изменить структуру в функции | передать `*T`; по значению — работа с копией |

## Ловушки

- ⚠️ Передача структуры по значению копирует её целиком: изменения внутри функции теряются.
- ⚠️ Позиционный литерал молча меняет смысл при перестановке полей одного типа.
- ⚠️ Добавили в структуру слайс/мапу → она перестала быть сравнимой и годной как ключ мапы.
- ⚠️ Тэг с опечаткой (`json:"id` без кавычки, пробел после `:`) компилируется, но игнорируется; ловит `go vet`.
- ⚠️ Неэкспортируемые поля (`name`) не видит `encoding/json` — ни при маршалинге, ни при разборе.
- ⚠️ Embedding — не наследование: нет полиморфизма по базовому типу и «виртуальных» методов.
