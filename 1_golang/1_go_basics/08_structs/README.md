# Тема 08. Структуры (Structs)

Этот раздел посвящен изучению структур в Go: инициализации, встраивания (embedding) как альтернативы наследованию, выравнивания полей в памяти (struct alignment) и использования метатегов для сериализации.

## 📋 Пререквизиты

*   Пройдена предыдущая тема: [07_functions](../07_functions/).

> ⏩ **Забегание вперёд.** Некоторые примеры и упражнения используют конструкции из следующих тем:
> *   Методы подробно — в [2_oop/01_methods](../../2_oop/01_methods/), встраивание — в [2_oop/03_embedding](../../2_oop/03_embedding/).
> *   Пример `02_system_infrastructure` измеряет размер структур через `unsafe.Sizeof` — пакет `unsafe` разбирается в [7_under_the_hood/05_reflection_unsafe](../../7_under_the_hood/05_reflection_unsafe/).

## 🗂 Структура раздела

*   **[01_theory/](./01_theory/)** — теория (разбита по подтемам):
    *   [01_declaration_and_init.md](./01_theory/01_declaration_and_init.md) — объявление структур, экспортируемые и приватные поля, идиоматическая инициализация по именам полей, нулевое значение (zero value), анонимные структуры и сравнимость структур.
    *   [02_embedding.md](./01_theory/02_embedding.md) — композиция вместо наследования: встраивание (embedding), продвижение полей и методов, конфликт имён (shadowing).
    *   [03_tags.md](./01_theory/03_tags.md) — тэги структур (struct tags), их использование в `encoding/json` и ORM, чтение через рефлексию.
    *   [04_memory_alignment.md](./01_theory/04_memory_alignment.md) — **выравнивание полей в памяти (struct alignment), padding и правило порядка полей с ASCII-схемами (разница между 24 и 16 байтами)**.
    *   [05_use_cases.md](./01_theory/05_use_cases.md) — практические применения: конфигурация через встраивание, оптимизация памяти, JSON-сериализация, проектирование под нулевое значение, копия против указателя.
*   **[02_examples/](./02_examples/)** — практические примеры:
    *   [01_cli_utilities](./02_examples/01_cli_utilities/main.go) — пример конфигурации сервера с встраиванием (`BaseConfig` в `ServerConfig`) и переопределением полей.
    *   [02_system_infrastructure](./02_examples/02_system_infrastructure/main.go) — замер размера структур в памяти с помощью `unsafe.Sizeof` для оптимизации выравнивания полей (разница между 24 и 16 байтами).
    *   [03_product_backend](./02_examples/03_product_backend/main.go) — **маршалинг и унмаршалинг структур с кастомными json-тэгами и использованием флага `omitempty`**.
*   **[03_exercises/](./03_exercises/)** — интерактивные задачи для самопроверки с автопроверками `PASS`/`FAIL`:
    *   `01_declaration` — объявление структуры `Movie` с экспортируемыми полями.
    *   `02_constructor` — написание конструктора `NewUser`, возвращающего указатель.
    *   `03_method_value_receiver` — вычисление площади прямоугольника методом с ресивером по значению.
    *   `04_method_pointer_receiver` — изменение счетчика методом с ресивером по указателю.
    *   `05_embedded_struct` — создание структуры `Employee`, расширяющей встроенный `Person`.
    *   `06_struct_tags` — настройка json-тэгов структуры для сопоставления полей.
    *   `07_zero_values` — проектирование структуры форматирования логов с полезным нулевым значением по умолчанию.
    *   `08_copy_vs_pointer` — **доказательство изоляции копий структур при передаче по значению против передачи по указателю**.
*   **[04_exercises_answers/](./04_exercises_answers/)** — эталонные решения.

## 🚀 Как проходить тему

1. Прочитайте теорию по порядку, начиная с [01_declaration_and_init.md](./01_theory/01_declaration_and_init.md).
2. Запустите и изучите примеры из папки `02_examples/` через `go run`:
   ```bash
   go run ./02_examples/02_system_infrastructure/main.go
   ```
3. Выполните задачи в `03_exercises/`. Запустите встроенный тест для самопроверки:
   ```bash
   go run ./03_exercises/07_zero_values/main.go
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.
