# Указатель на указатель (`**T`)

`**T` — указатель на указатель. В обычном Go-коде встречается редко, но знать нужно.

## Синтаксис

```go
x := 10
p := &x     // *int
pp := &p    // **int

fmt.Println(**pp) // 10
**pp = 42
fmt.Println(x)    // 42
```

## Зачем бывает нужен

1. **Функция должна заменить сам указатель, а не только значение.**

```go
func resetTo(pp **int, v int) {
    nv := v
    *pp = &nv
}

var p *int
resetTo(&p, 7)
fmt.Println(*p) // 7
```

2. **Linked-структуры.** Голова односвязного списка иногда удобна как `**Node`, чтобы упростить удаление первого элемента.

3. **API C-интеропа.** `cgo` и многие внешние библиотеки через `**T` отдают выходные буферы.

## Чего делать не стоит

- Использовать `**T` «просто так» вместо `*T`: читаемость падает сильнее, чем польза.
- Возвращать `**T` из публичных функций — в 95% случаев можно обойтись одним указателем или структурой-оберткой.

## Связка с интерфейсами

Интерфейсная переменная уже содержит указатель внутри. `**MyInterface` почти всегда — сигнал, что что-то спроектировано не так.
