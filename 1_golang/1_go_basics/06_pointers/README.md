# Тема 06. Указатели (Pointers)

Этот раздел посвящён указателям в Go: операторам взятия адреса `&` и разыменования `*`, разнице между семантикой значений и указателей, receiver'ам методов, безопасности при работе с `nil`, указателям на указатели и типичным сценариям применения в бэкенд-разработке.

## 📋 Пререквизиты

*   Пройдена предыдущая тема: [05_control_flow](../05_control_flow/).

> ⏩ **Забегание вперёд.** Некоторые примеры и упражнения используют конструкции из следующих тем:
> *   Указатели почти всегда используются со структурами и методами: структуры — в [08_structs](../08_structs/), методы и receiver'ы — в [2_oop/01_methods](../../2_oop/01_methods/). В этой теме (`03_pointer_receiver`, примеры) достаточно понимать, что получатель метода — обычный параметр: значение копируется, указатель — нет.

    *   `06_pointer_to_pointer` — чтение значения через двойной указатель `**int`.
    *   `07_slice_pointer` — модификация элементов слайса vs добавление элементов через append по указателю.

## 🚀 Как проходить тему

1. Прочитайте теорию по порядку, начиная с [01_basics.md](./01_theory/01_basics.md) и далее до [06_use_cases.md](./01_theory/06_use_cases.md).
2. Запустите и изучите примеры из папки `02_examples/` через `go run`:
   ```bash
   go run ./02_examples/03_product_backend/main.go
   ```
3. Выполните задачи в `03_exercises/`. Запустите встроенный тест для самопроверки:
   ```bash
   go run ./03_exercises/07_slice_pointer/main.go
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.
