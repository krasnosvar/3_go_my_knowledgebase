# Тема 01. Переменные и константы (Variables & Constants)

Этот раздел посвящен базовым механизмам объявления переменных и констант в Go, правилам областей видимости и типичным ловушкам рантайма (таким как shadowing).

## 📋 Пререквизиты

*   Установлен Go 1.22+ и понятно, как запускать код (см. раздел «0. Подготовка» в [корневом README](../../README.md)).

> ⏩ **Забегание вперёд.** Некоторые примеры и упражнения используют конструкции из следующих тем:
> *   Проверки в упражнениях используют `if` ([05_control_flow](../05_control_flow/)), `fmt.Printf` ([03_fmt_and_output](../03_fmt_and_output/)) и простые функции ([07_functions](../07_functions/)). Пока читайте эту обвязку как готовый код — менять нужно только места с `TODO`.
> *   Упражнение `05_zero_values` возвращает указатель `*int` — указатели разбираются в [06_pointers](../06_pointers/); пример `03_product_backend` использует побитовые операции из [04_operators_bitwise](../04_operators_bitwise/).

## 🚀 Как проходить тему

1. Прочитайте главный учебник по переменным: [01_vars_and_zero_values.md](./01_theory/01_vars_and_zero_values.md).
2. Запустите и изучите примеры из папки `02_examples/` через `go run`:
   ```bash
   go run ./02_examples/01_cli_utilities/main.go
   ```
3. Выполните задачи в `03_exercises/`. Запустите встроенный тест для самопроверки:
   ```bash
   go run ./03_exercises/07_shadowing/main.go
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.
