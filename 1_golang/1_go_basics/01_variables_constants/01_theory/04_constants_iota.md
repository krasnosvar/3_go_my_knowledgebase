# const и iota

## const

Константа фиксируется на этапе компиляции и не может быть изменена.

```go
const Pi = 3.14159
const AppName = "ewa"

const (
    MaxRetries  = 3
    DefaultPort = 8080
)
```

Особенности:

- Значение должно быть **constant expression** (литералы, арифметика над литералами, другие константы).
- Тип можно не указывать — Go подставит по контексту (untyped const). Так `const N = 10` можно использовать и как `int`, и как `int64`.
- Явный тип (`const N int32 = 10`) зафиксирует тип сразу.

## iota — генератор последовательных значений

`iota` — целочисленный счётчик внутри блока `const`, начинается с 0.

```go
const (
    Sunday = iota // 0
    Monday        // 1
    Tuesday       // 2
    Wednesday     // 3
)
```

### Enum-like с именованным типом

```go
type Status int

const (
    StatusPending Status = iota
    StatusActive
    StatusDone
)
```

### Со смещением

```go
const (
    _ = iota // пропускаем 0
    KB = 1 << (10 * iota)
    MB
    GB
    TB
)
```

### Битовые флаги

```go
type Perm int
const (
    PermRead    Perm = 1 << iota // 1
    PermWrite                    // 2
    PermExecute                  // 4
)
```

## Нюансы

- iota сбрасывается в 0 в каждом новом блоке `const ( ... )`.
- iota инкрементируется на **каждую строку** блока, даже если она пустая или просто `_`.
- Для «чего-то кроме чисел» iota не подходит — строки делаются через stringer или руками.

## Зачем нужны именованные константы

Не магические числа в коде, а явные имена — читается и сопровождается проще. Особенно это важно для enum-подобных значений статусов, кодов, флагов.
