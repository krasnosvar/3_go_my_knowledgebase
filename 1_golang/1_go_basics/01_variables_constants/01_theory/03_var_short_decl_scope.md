# var, := и область видимости

## var — универсальное объявление

```go
var a int           // a == 0
var b int = 10      // с явным значением
var c = 10          // тип выводится (int)
var x, y int = 1, 2 // несколько сразу
```

Работает и внутри функции, и на уровне пакета.

## := — короткое объявление

```go
a := 10
name, age := "den", 30
```

Правила:

- работает **только внутри функций**;
- хотя бы одно имя слева должно быть **новым**, остальные могут «переприсваиваться»:

```go
a, err := foo()   // объявили обе
a, err = bar()    // обе уже есть — обычный assign
a, b, err := baz() // ок: b новая, a и err просто переприсваиваются
// a, err := qux() // ошибка компиляции: no new variables on left side of :=
```

## var vs :=

| Контекст | Предпочтительно |
|---|---|
| Уровень пакета | `var` |
| Локально, понятный тип | `:=` |
| Нужен явный тип (для интерфейсов, zero-init) | `var` |
| `var x *T` без значения | `var` |

## Область видимости

Scope ограничен блоком `{}`, в котором переменная объявлена. Пакетный уровень — видна во всём пакете (экспортируется по заглавной букве).

```go
func f() {
    if ok := check(); ok {
        // ok видна только внутри if/else
    }
    // здесь ok уже нет
}
```

Переменные `if/for/switch` с инициализацией живут только в них — это помогает держать scope узким.

## Неиспользованные переменные

Go считает неиспользованные локальные переменные ошибкой компиляции. Это заставляет держать код чистым. Лайфхак:

```go
_ = x // явно говорим "нам не нужно"
```

Использовать `_` вместо удаления нежелательно — лучше убрать переменную.
