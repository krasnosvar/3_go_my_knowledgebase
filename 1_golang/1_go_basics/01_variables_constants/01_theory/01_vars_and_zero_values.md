# Объявление переменных и нулевые значения (zero values)

В Go переменная всегда имеет тип и всегда инициализирована: если значение не задано явно, переменная получает **нулевое значение** (zero value) своего типа. Неинициализированного «мусора» в памяти, как в C, здесь не бывает.

## Способы объявления переменных

В Go есть два основных способа объявить переменную.

```go
var a int           // a == 0 (нулевое значение)
var b int = 10      // с явным типом и значением
var c = 10          // тип выводится из значения (int)
var x, y int = 1, 2 // несколько сразу

name := "den"       // короткое объявление, тип выводится
```

## Справочная таблица: var vs :=

| Способ объявления | Где работает | Требует явный тип? | Когда использовать |
| :--- | :--- | :--- | :--- |
| **`var name type`** | Везде (на уровне пакета и локально) | Да | Инициализация дефолтным нулевым значением, объявление интерфейсов. |
| **`var name = value`** | Везде (на уровне пакета и локально) | Нет (тип выводится) | Глобальные переменные пакета с начальным значением. |
| **`name := value`** | Только внутри функций | Нет (тип выводится) | Локальные переменные. Быстрое объявление по месту. |

Подробнее про области видимости и правила `:=` — в файле [03_var_short_decl_scope.md](./03_var_short_decl_scope.md).

### Правило краткого объявления (`:=`)

Конструкция `:=` объявляет **новые** переменные и присваивает им значения. Но есть исключение: если слева от `:=` перечислено несколько переменных, хотя бы одна из них **обязана быть новой**. Остальные переменные в этом случае будут просто перезаписаны (переприсвоены), а не объявлены заново.

```go
a, err := doSomething() // Объявляет a и err
b, err := doAnother()   // Объявляет b, но перезаписывает err! (Это легально)
a, b := doOneMore()     // Ошибка компиляции: нет новых переменных слева!
```

## Нулевые значения (zero values)

Если переменная объявлена без явного значения, она получает нулевое значение своего типа:

| Тип | Нулевое значение |
| :--- | :--- |
| Числовые (`int`, `float64`, ...) | `0` |
| `bool` | `false` |
| `string` | `""` (пустая строка) |
| Указатели, `func`, `interface`, `map`, `slice`, `chan` | `nil` |
| Структуры | структура, где каждое поле равно своему нулевому значению |

```go
var i int       // 0
var f float64   // 0
var s string    // ""
var ok bool     // false
var p *int      // nil
var m map[string]int // nil
```

⚠️ Нулевое значение `map`, `slice` и `chan` — это `nil`. Из nil-слайса и nil-мапы можно читать, но запись в nil-мапу вызовет панику — её нужно сначала создать через `make`.

## Неиспользованные переменные

Go считает неиспользованную локальную переменную ошибкой компиляции. Это заставляет держать код чистым. Если значение действительно не нужно, используется пустой идентификатор `_`:

```go
_, err := doSomething() // первое значение отбрасываем
```
