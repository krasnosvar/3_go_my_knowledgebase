# Bitwise-маски и флаги

Базовые побитовые операторы (`&`, `|`, `^`, `&^`, `<<`, `>>`) разобраны в `02_bitwise_basics.md`. Здесь — как собирать из них маски и флаги.

## Паттерн: флаги

Определяем флаги как степени двойки:

```go
type Perm uint8
const (
    PermRead    Perm = 1 << iota // 00000001
    PermWrite                    // 00000010
    PermExecute                  // 00000100
    PermAdmin                    // 00001000
)
```

Установить флаг:

```go
p := PermRead | PermWrite
```

Проверить:

```go
if p&PermRead != 0 { /* есть */ }
```

Снять:

```go
p = p &^ PermWrite
```

Переключить:

```go
p = p ^ PermExecute
```

Проверить «все из маски»:

```go
mask := PermRead | PermAdmin
if p&mask == mask { /* оба есть */ }
```

## Packed-поля

Несколько значений в одном целом:

```go
// 4 младших бита — уровень лога, биты 4-7 — категория
level := packed & 0x0F
cat   := (packed >> 4) & 0x0F
```

Полезно в низкоуровневых форматах (протоколы, файлы). В обычном приложении лучше struct.

## Маска как константа

```go
const LowerByte = 0xFF
lo := value & LowerByte
```

## Проверка степени двойки

```go
isPow2 := x > 0 && x&(x-1) == 0
```

Классический трюк, `x & (x-1)` «сбрасывает» младший установленный бит.

## Когда не пользоваться

- Если вместо флагов подошёл `struct{ Read, Write bool }` — не гонись за упаковкой.
- В hot path JSON-сериализации битовая маска неудобна.
- Читаемость всегда важнее «на 4 бита меньше».
