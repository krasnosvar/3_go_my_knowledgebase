# Операторы: базовый набор

## Арифметические

```go
a + b
a - b
a * b
a / b
a % b
```

- `/` для целых — целочисленное деление (`7 / 2 == 3`).
- `%` — только для целых.
- Overflow для знаковых — wrap-around без panic.

## Сравнения

```go
a == b
a != b
a < b
a > b
a <= b
a >= b
```

Возвращают `bool`. Для `float` сравнение на равенство ненадёжно (`0.1+0.2 == 0.3` → false), используй epsilon.

## Логические

```go
a && b
a || b
!a
```

Работают **только с bool** — нет автоматического приведения `int` или указателя к `bool`.

Короткое замыкание: правый операнд вычисляется, только если левый не определил результат.

```go
if u != nil && u.Admin { /* ... */ }
```

## Побитовые

```go
a & b   // AND
a | b   // OR
a ^ b   // XOR
a &^ b  // AND NOT (bit clear)
a << n  // сдвиг влево
a >> n  // сдвиг вправо
```

Работают на целых типах. Подробнее — в `02_bitwise_basics.md`.

## Присваивания

```go
a = 1       // обычное
a += 1      // составные: += -= *= /= %= &= |= ^= <<= >>= &^=
```

Оператор `a++` — statement, не выражение: его нельзя использовать внутри `if` или присваивания.

## Приоритет

В Go всего 5 уровней приоритета (меньше, чем в C). В порядке убывания:

```
5: * / % << >> & &^
4: + - | ^
3: == != < <= > >=
2: &&
1: ||
```

Если сомневаешься — ставь скобки. Это дешевле отладки.

> ⚠️ Частый вопрос на собеседовании: в отличие от C, где побитовые операторы имеют очень низкий приоритет (ниже сравнений), в Go `&`, `|`, `^`, `&^` имеют высокий приоритет (наравне с арифметическими). Поэтому выражение `if a & mask == mask` в Go скомпилируется и сработает корректно (сначала `a & mask`, затем `==`), тогда как в C оно сработало бы неверно без скобок. Для читаемости скобки всё равно рекомендуются.

## Адресные

```go
&x  // взять адрес
*p  // разыменовать
```

И канальные:

```go
ch <- v    // отправить
v := <-ch  // получить
```

— отдельный оператор для каналов, не путай с побитовым shift.
