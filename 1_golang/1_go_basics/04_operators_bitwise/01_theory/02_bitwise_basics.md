# Побитовые операторы: основы (AND / OR / XOR / NOT)

Побитовые операции работают непосредственно с битами целочисленных типов (`int`, `uint`, `byte` и др.) в их двоичном представлении.

## Таблица побитовых операторов

| Оператор | Название | Описание | Пример |
| :--- | :--- | :--- | :--- |
| `&` | Побитовое **И** (AND) | Возвращает 1, если оба бита равны 1. | `5 & 3` → `0101 & 0011 = 0001` (1) |
| `\|` | Побитовое **ИЛИ** (OR) | Возвращает 1, если хотя бы один бит равен 1. | `5 \| 3` → `0101 \| 0011 = 0111` (7) |
| `^` | Побитовое **XOR** | Возвращает 1, если биты различаются. Также используется как унарное отрицание (НЕ). | `5 ^ 3` → `0101 ^ 0011 = 0110` (6) |
| `&^` | Побитовое **И НЕ** (AND NOT / Bit Clear) | Сбрасывает в 0 биты первого числа, если во втором числе соответствующие биты равны 1. | `5 &^ 3` → `0101 &^ 0011 = 0100` (4) |
| `<<` | Сдвиг влево | Сдвигает биты влево на N позиций, заполняя нулями справа. | `3 << 2` → `00000011 -> 00001100` (12) |
| `>>` | Сдвиг вправо | Сдвигает биты вправо на N позиций. Для unsigned заполняет нулями, для signed — знаком. | `12 >> 2` → `00001100 -> 00000011` (3) |

Сдвиги `<<` и `>>` подробно разобраны в `04_shift_rules.md`, маски и флаги — в `03_bitwise_masks.md`.

## Унарное НЕ (`^`)

В Go нет отдельного оператора `~` (как в C). Побитовое отрицание записывается унарным `^`:

```go
var x uint8 = 0b0000_1111
^x // 0b1111_0000 — все биты инвертированы
```

## Оператор сброса битов (AND NOT: `&^`)

Оператор `&^` — уникальная фича Go, которая заменяет громоздкую конструкцию из C `a & ~b`.

Визуальная схема работы `&^`:

```
  a = 1 0 1 0 1 1 0 0  (исходные биты)
  b = 0 0 0 0 1 1 0 0  (маска битов для сброса — установлены 3-й и 2-й биты)
  -------------------
  a &^ b = 1 0 1 0 0 0 0 0  (биты, которые были установлены в b, сброшены в a)
```

Пример в коде:

```go
flags := 0b1011  // Включены флаги 1, 2, 8
mask := 0b0011   // Флаги 1, 2 для сброса

result := flags &^ mask // Результат: 0b1000 (остался только флаг 8)
```

## Быстрые проверки на битах

На низком уровне побитовые операции выполняются за 1 такт процессора и широко применяются для оптимизаций.

### Проверка чётности числа

Вместо операции остатка от деления `% 2`:

```go
isOdd := (n & 1) != 0 // true, если число нечётное (младший бит равен 1)
```

### Проверка, является ли число степенью двойки

Классический алгоритм за константное время:

```go
isPowerOfTwo := n > 0 && (n & (n - 1)) == 0
```

*Почему это работает*: у степени двойки установлена ровно одна единица (например, `8` = `1000`). Число `n - 1` будет содержать нули на месте единиц и единицы на месте всех младших бит (`7` = `0111`). Побитовое И для них даст `0`.
