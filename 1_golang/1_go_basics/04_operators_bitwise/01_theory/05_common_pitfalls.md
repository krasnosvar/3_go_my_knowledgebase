# Частые ошибки операторов и битовых операций

## 1. Переполнение без предупреждения

```go
var x int32 = 2_000_000_000
x + x // -294_967_296, wrap-around
```

Go не бросает ошибок на overflow. Следи за типами при работе с большими числами, используй `int64` или `math/big`.

## 2. Смешение signed и unsigned

```go
var a int = -1
var b uint = 1
// a < b // ошибка компиляции — типы разные
```

Компилятор не позволит без явного приведения. Если приведёшь неаккуратно — получишь сюрприз:

```go
_ = uint(a) // огромное положительное
```

## 3. Деление на ноль

- `a / 0` для целых — **panic** в рантайме.
- Для float — `+Inf`, `-Inf` или `NaN`.

Проверяй знаменатель перед делением.

## 4. Приоритет операций

> ⚠️ Частый вопрос на собеседовании: `& == 0` — частая ловушка.

```go
if p & PermRead == 0 { /* ок */ }
```

Работает, потому что `&` выше `==`. Но если начинаешь смешивать много операторов без скобок — поставь их явно, отладка дороже.

## 5. Shift отрицательным числом

```go
n := -1
_ = 1 << n // panic: negative shift count
```

Гарантируй неотрицательный `n`.

## 6. Несовместимые типы в побитовых операциях

```go
var a uint8 = 1
var b int = 2
_ = a | b // ошибка: mismatched types
```

Приведи явно к одному типу.

## 7. Сравнение float на равенство

```go
if 0.1 + 0.2 == 0.3 { } // false
```

Используй epsilon:

```go
math.Abs(x - y) < 1e-9
```

## 8. Перепутать `&&` и `&`

```go
if x != nil & x.Ok() { } // плохо: & посчитает битовый AND двух bool результатов
```

Всегда `&&` / `||` для булевой логики, `&` / `|` — для чисел.

## 9. Потеря битов при неявных приведениях

```go
var big uint32 = 0x1_FF_FF_FF_FF
var small uint16 = uint16(big) // берёт только младшие 16 бит
```

Без ошибки, без предупреждения. Следи за сужающими приведениями.
