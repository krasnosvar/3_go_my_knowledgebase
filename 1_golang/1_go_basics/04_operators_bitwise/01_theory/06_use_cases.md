# Use-cases операторов и битовых операций

## 1. Права доступа и роли

Набор разрешений удобно держать битовой маской:

```go
type Perm uint8
const (
    PermRead Perm = 1 << iota
    PermWrite
    PermDelete
    PermAdmin
)

user.Perms = PermRead | PermWrite

if user.Perms&PermAdmin != 0 {
    // admin-only
}
```

Компактно, читабельно, быстро.

## 2. Флаги конфигурации

Опции фичи/запуска:

```go
type Mode uint
const (
    ModeDebug Mode = 1 << iota
    ModeVerbose
    ModeDryRun
)
```

Комбинируются через `|`, проверяются через `&`.

## 3. Размеры и буферы

```go
const (
    KiB = 1 << 10 // 1024
    MiB = 1 << 20
)

buf := make([]byte, 4*MiB)
```

`<<` читается лучше, чем «магическая» 4194304.

## 4. Packed-форматы

Протоколы с компактным заголовком (упаковка нескольких полей в один байт/слово):

```go
version := header >> 4
kind    := header & 0x0F
```

## 5. Checksum и hash-эквивалентность

Быстрое XOR-сравнение/быстрые хэши для вспомогательных нужд. Для криптостойкости — `crypto/sha256`, а не XOR.

## 6. Степени двойки

```go
isPow2 := x > 0 && x&(x-1) == 0
```

Удобно для round-up:

```go
n = (n + align - 1) &^ (align - 1) // выравнивание по степени двойки
```

## 7. Set of small ints

Множество чисел 0..63 умещается в `uint64`, что иногда быстрее map:

```go
var seen uint64
seen |= 1 << v
if seen&(1<<v) != 0 { /* уже было */ }
```

## Когда не использовать

- Бизнес-логика. «Чем умнее хак, тем хуже поддержка». Маски уместны в библиотеках, протоколах, драйверах, рантайм-оптимизациях — но не в CRUD-сервисе.
- Когда проще struct из bool.
