# Упражнения: Тема 04. Операторы и побитовые операции (Operators & Bitwise)

Каждая задача — это `main.go` с заготовкой (`TODO`) и встроенной самопроверкой, печатающей `PASS` или `FAIL`. Заготовки компилируются сразу (в стартовом состоянии проверки печатают `FAIL`) — ваша цель довести их до `PASS`.

Команды запускаются из папки темы (`04_operators_bitwise/`):

```bash
go run ./03_exercises/01_arithmetic                 # заготовка
go run ./04_exercises_answers/01_arithmetic_answers # эталонное решение
```
