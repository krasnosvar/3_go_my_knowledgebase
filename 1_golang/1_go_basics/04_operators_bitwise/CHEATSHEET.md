# Операторы и битовые операции — шпаргалка

Подробности и объяснения — в [01_theory/](./01_theory/). ⚠️ — частая ловушка.

## Операторы

Подробно: [01_operators_basics.md](./01_theory/01_operators_basics.md).

| Группа | Операторы | Заметки |
| :--- | :--- | :--- |
| Арифметика | `+ - * / %` | целое `/` отбрасывает дробь к нулю: `7/2 == 3`, `-7/2 == -3`; `%` только для целых, знак — как у делимого: `-7%2 == -1` |
| Сравнение | `== != < <= > >=` | результат `bool`; операнды одного типа |
| Логика | `&& \|\| !` | только `bool`; короткое замыкание: `u != nil && u.Admin` |
| Побитовые | `& \| ^ &^ << >>` | только целые; унарный `^x` — инверсия |
| Присваивание | `= += -= *= /= %= &= \|= ^= <<= >>= &^=` | — |
| Инкремент | `x++`, `x--` | statement, не выражение: `y = x++` не компилируется |
| Адрес | `&x`, `*p` | взять адрес / разыменовать |
| Каналы | `ch <- v`, `v := <-ch` | отправить / получить |

| Приоритет (сверху выше) | Операторы |
| :--- | :--- |
| 5 | `*  /  %  <<  >>  &  &^` |
| 4 | `+  -  \|  ^` |
| 3 | `==  !=  <  <=  >  >=` |
| 2 | `&&` |
| 1 | `\|\|` |

`p&mask == mask` в Go работает без скобок (`&` выше `==`), в C — нет.

## Побитовые операции

Подробно: [02_bitwise_basics.md](./01_theory/02_bitwise_basics.md).

| Оператор | Смысл | Пример |
| :--- | :--- | :--- |
| `&` | AND: 1, если оба 1 | `5 & 3` → `0101 & 0011 = 0001` (1) |
| `\|` | OR: 1, если хоть один 1 | `5 \| 3` → `0111` (7) |
| `^` (бинарный) | XOR: 1, если различаются | `5 ^ 3` → `0110` (6) |
| `^x` (унарный) | NOT, аналог `~` из C | `^uint8(0b0000_1111)` → `0b1111_0000` |
| `&^` | AND NOT (bit clear), аналог `a & ~b` | `5 &^ 3` → `0100` (4) |
| `<<` | сдвиг влево, ×2ⁿ | `3 << 2` → 12 |
| `>>` | сдвиг вправо: unsigned — нулями, signed — знаком | `12 >> 2` → 3; `int8(-8) >> 1` → −4 |

| Трюк | Код |
| :--- | :--- |
| Нечётное | `n&1 != 0` |
| Степень двойки | `n > 0 && n&(n-1) == 0` |
| Сбросить младший установленный бит | `x & (x-1)` |
| Выровнять вверх по степени двойки | `(n + align - 1) &^ (align - 1)` |
| Младший байт | `v & 0xFF` |
| Размеры | `KiB = 1 << 10`, `MiB = 1 << 20` |
| Множество чисел 0..63 | `var seen uint64; seen \|= 1 << v; seen&(1<<v) != 0` |

## Маски и флаги

Подробно: [03_bitwise_masks.md](./01_theory/03_bitwise_masks.md).

| Задача | Код |
| :--- | :--- |
| Объявить флаги | `type Perm uint8` + `const ( PermRead Perm = 1 << iota; PermWrite; PermExec )` |
| Собрать набор | `p := PermRead \| PermWrite` |
| Установить | `p \|= PermExec` |
| Проверить один | `p&PermRead != 0` |
| Проверить все из маски | `p&mask == mask` |
| Проверить хотя бы один | `p&mask != 0` |
| Снять | `p &^= PermWrite` |
| Переключить | `p ^= PermExec` |
| Packed-поля | `lo := packed & 0x0F`; `hi := (packed >> 4) & 0x0F` |

## Сдвиги

Подробно: [04_shift_rules.md](./01_theory/04_shift_rules.md).

| Правило | Детали |
| :--- | :--- |
| Счётчик `n` | целое; signed разрешён с Go 1.13 |
| `n < 0` в рантайме | panic `negative shift amount` |
| Константа `n` ≥ ширины типа | ошибка компиляции (`int32(1) << 32`) |
| Переменная `n` ≥ ширины типа | результат 0 (для signed `>>` отрицательного — −1) |
| Вытолкнутые биты | теряются без ошибки: `uint8(0x80) << 1` → 0 |
| Untyped константа слева | берёт тип из контекста: `var u uint32 = 1 << 20` |

```go
package main

import "fmt"

type Perm uint8

const (
	PermRead  Perm = 1 << iota // 0001
	PermWrite                  // 0010
	PermExec                   // 0100
	PermAdmin                  // 1000
)

func main() {
	fmt.Println(7/2, -7/2, 7%2, -7%2) // 3 -3 1 -1
	fmt.Println(5&3, 5|3, 5^3, 5&^3)  // 1 7 6 4

	var x uint8 = 0b0000_1111
	fmt.Printf("%08b\n", ^x) // 11110000

	var b int8 = -8
	fmt.Println(b>>1, 3<<2, 12>>2) // -4 12 3

	p := PermRead | PermWrite
	p |= PermExec                               // установить
	p &^= PermWrite                             // снять
	p ^= PermAdmin                              // переключить
	fmt.Printf("%04b %v\n", p, p&PermRead != 0) // 1101 true
	mask := PermRead | PermAdmin
	fmt.Println(p&mask == mask) // true: & выше ==

	n := 64
	fmt.Println(n > 0 && n&(n-1) == 0, n&1 != 0) // true false
	align := 8
	fmt.Println((13 + align - 1) &^ (align - 1)) // 16

	var i32 int32 = 2_000_000_000
	fmt.Println(i32 + i32) // -294967296

	var seen uint64
	for _, v := range []int{3, 5, 3} {
		if seen&(1<<v) != 0 {
			fmt.Println("повтор:", v) // повтор: 3
		}
		seen |= 1 << v
	}
}
```

## Когда маски уместны

Подробно: [06_use_cases.md](./01_theory/06_use_cases.md).

| Да | Нет |
| :--- | :--- |
| права и роли, флаги режимов (`ModeDebug \| ModeDryRun`) | бизнес-логика CRUD-сервиса |
| протоколы, бинарные заголовки (`version := header >> 4`) | когда хватает `struct{ Read, Write bool }` |
| размеры буферов, выравнивание | криптостойкий хэш (это `crypto/sha256`, не XOR) |

## Ловушки

Подробно: [05_common_pitfalls.md](./01_theory/05_common_pitfalls.md).

- ⚠️ Переполнение молчит: `int32(2_000_000_000) * 2` → `-294967296`; брать `int64` / `math/big`.
- ⚠️ `int` и `uint` (и `uint8` с `int`) не смешиваются — ошибка `mismatched types`; приводить явно.
- ⚠️ `uint(-1)` из переменной → `18446744073709551615`.
- ⚠️ Целое деление на ноль → panic `integer divide by zero`; float → `+Inf`, `-Inf`, `NaN`.
- ⚠️ `==` для float-переменных ненадёжно: `math.Abs(x-y) < 1e-9`.
- ⚠️ `&` и `|` к `bool` не применяются (ошибка компиляции) — для логики только `&&` / `||`.
- ⚠️ Сужающее приведение (`uint16(u32)`) берёт только младшие биты, без предупреждения.
- ⚠️ Сдвиг на отрицательную переменную → panic; гарантировать `n >= 0`.
- ⚠️ Сложные выражения без скобок читаются плохо — ставить скобки, даже если приоритет верный.
