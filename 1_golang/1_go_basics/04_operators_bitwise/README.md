# Тема 04. Операторы и побитовые операции (Operators & Bitwise)

Этот раздел посвящён операторам Go: сначала обычным (арифметика, сравнение, логика, приоритет), затем побитовым — операторам `&`, `|`, `^`, `&^` (AND NOT), сдвигам `<<`/`>>`, битовым маскам и флагам доступа, типичным ловушкам и практическим применениям.

## 🗂 Структура раздела

*   **[01_theory/](./01_theory/)** — теория:
    *   [01_operators_basics.md](./01_theory/01_operators_basics.md) — обычные операторы: арифметические, сравнения, логические, присваивания, приоритет, адресные и канальные.
    *   [02_bitwise_basics.md](./01_theory/02_bitwise_basics.md) — побитовые основы: AND/OR/XOR/NOT, оператор сброса битов `&^`, быстрые проверки (чётность, степень двойки).
    *   [03_bitwise_masks.md](./01_theory/03_bitwise_masks.md) — маски и флаги: установка/проверка/сброс/переключение битов, packed-поля.
    *   [04_shift_rules.md](./01_theory/04_shift_rules.md) — правила сдвигов влево и вправо: переполнение, знаковый сдвиг, ограничения на счётчик сдвига.
    *   [05_common_pitfalls.md](./01_theory/05_common_pitfalls.md) — частые ошибки: переполнение, смешение signed/unsigned, приоритет, `&&` vs `&`, сужающие приведения.
    *   [06_use_cases.md](./01_theory/06_use_cases.md) — практические применения: права доступа, флаги конфигурации, размеры буферов, packed-форматы, множества малых чисел.
*   **[02_examples/](./02_examples/)** — практические примеры:
    *   [01_cli_utilities](./02_examples/01_cli_utilities/main.go) — управление Unix-подобными флагами прав доступа с помощью побитового ИЛИ (`|`), И (`&`) и И НЕ (`&^`).
    *   [02_system_infrastructure](./02_examples/02_system_infrastructure/main.go) — хранение и обработка системных алертов (CPU/RAM/Disk) в едином байтовом регистре состояний.
    *   [03_product_backend](./02_examples/03_product_backend/main.go) — фильтрация атрибутов товаров в интернет-магазине с помощью битовых масок.
*   **[03_exercises/](./03_exercises/)** — интерактивные задачи для самопроверки с автопроверками `PASS`/`FAIL`:
    *   `01_arithmetic` — простые арифметические вычисления.
    *   `02_comparison` — операции сравнения.
    *   `03_logic` — логическое И/ИЛИ/НЕ для прав пользователей.
    *   `04_bitwise_and_or_xor` — применение побитовых `&`, `|` и `^`.
    *   `05_bit_shift` — быстрое умножение и деление через сдвиги `<<` и `>>`.
    *   `06_masks` — проверка, установлен ли бит в заданной позиции.
    *   `07_flags` — установка флагов через `|`, сброс через `&^` и проверка через `&`.
    *   `08_toggle_bits` — переключение (toggle) бита с помощью XOR `^`.
*   **[04_exercises_answers/](./04_exercises_answers/)** — эталонные решения.

## 🚀 Как проходить тему

1. Прочитайте теорию по порядку, начиная с [01_operators_basics.md](./01_theory/01_operators_basics.md) и далее к побитовым операциям.
2. Запустите и изучите примеры из папки `02_examples/` через `go run`:
   ```bash
   go run ./02_examples/01_cli_utilities/main.go
   ```
3. Выполните задачи в `03_exercises/`. Запустите встроенный тест для самопроверки:
   ```bash
   go run ./03_exercises/07_flags/main.go
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.
