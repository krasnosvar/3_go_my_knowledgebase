# Слайсы: основы, Slice Header, len и cap

## Массив против слайса

Массив в Go имеет **фиксированный размер**, который является частью его типа (`[4]int` и `[5]int` — разные типы). Слайс — **динамическая** структура: его длина может меняться.

Слайс — это не массив. Слайс — это легковесная структура-дескриптор (**Slice Header**), которая указывает на сегмент реального массива (**Backing Array**, подлежащий массив), хранящего данные.

## Анатомия слайса: Slice Header

В стандартной библиотеке (пакет `reflect`) структура заголовка представлена так:

```go
type SliceHeader struct {
    Data uintptr // Указатель на первый элемент слайса в backing array
    Len  int     // Длина: текущее количество элементов
    Cap  int     // Емкость: максимальное количество элементов от Data до конца backing array
}
```

```
Slice Header                Backing Array
+-----------+
| Data  ----|------------->  [ e0 | e1 | e2 | e3 | e4 ]
| Len = 3   |                  ^                ^
| Cap = 5   |                 Data            конец cap
+-----------+
                            <------- len ------>
                            <---------- cap --------->
```

*   **`len`** (длина) — текущее количество доступных для чтения/записи элементов.
*   **`cap`** (ёмкость) — сколько элементов помещается в backing array от начала слайса до его конца.

## Способы создания слайсов

*   **Слайс-литерал**: `s := []int{10, 20, 30}` — при этом `len == cap == 3`.
*   **`make([]T, len, cap)`**: `s := make([]int, 2, 5)` — длина 2, ёмкость 5.
*   **Нарезка** существующего массива или слайса: `s := array[start:end]`.

## Передача слайса в функцию

Когда вы передаете слайс в функцию, **Slice Header копируется по значению** (копируются 24 байта на 64-битной платформе: указатель, длина, емкость).

Но так как указатель `Data` ссылается на тот же backing array, изменение **элементов** слайса внутри функции изменит их и в вызывающем коде.

> ⚠️ Частый вопрос на собеседовании: почему изменение элемента слайса внутри функции видно снаружи, а `append` внутри функции — нет? Потому что элементы лежат в общем backing array, а обновлённый Header (с новыми `len`/`cap`, а иногда и новым указателем) остаётся локальной копией и не возвращается в вызывающий код.
