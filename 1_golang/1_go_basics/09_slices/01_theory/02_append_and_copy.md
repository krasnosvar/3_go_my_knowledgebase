# append, рост ёмкости и copy

## Эффект append

Поведение `append` зависит от соотношения `len` и `cap`:

*   **Если `len < cap`**: вызов `append` записывает новые данные в свободные ячейки текущего backing array. Все слайсы, указывающие на эти ячейки, увидят изменения.
*   **Если `len == cap`**: свободного места нет. Go выделяет **новый backing array**, копирует туда старые данные, добавляет новые и возвращает слайс с указателем на новый массив. Связь со старым слайсом разрывается.

```go
s1 := []int{10, 20} // len=2, cap=2 (массив полон)
s2 := s1
s2 = append(s2, 30) // Выделился НОВЫЙ массив для s2!
s2[0] = 99          // Изменение s2 НЕ затронет s1!
```

Именно поэтому `append` нужно всегда присваивать обратно: `s = append(s, val)`. Иначе, если произойдёт переаллокация, вы потеряете новый Header с новым указателем и обновлённой длиной.

## Алгоритм роста ёмкости (Go 1.18+)

При превышении `cap` Go увеличивает ёмкость backing array по следующему правилу:

1.  Если новая требуемая ёмкость больше удвоенной старой, выбирается новая требуемая ёмкость.
2.  Иначе:
    *   Если старая ёмкость меньше **256**, она удваивается (`newcap = doublecap`).
    *   Если старая ёмкость ≥ 256, она увеличивается по формуле:

        ```
        newcap = oldcap + (oldcap + 3*256) / 4
        ```

        То есть коэффициент роста плавно снижается с 2.0x до примерно 1.25x по мере увеличения размера слайса.

> ⚠️ Частый вопрос на собеседовании: какой коэффициент роста у слайса? Ответ: для маленьких слайсов (cap < 256) — 2x, для больших — постепенно приближается к 1.25x.

## copy

Встроенная функция `copy(dst, src)` копирует элементы между слайсами и возвращает количество скопированных элементов (`min(len(dst), len(src))`). Она работает по общему backing array независимо: `dst` и `src` могут быть совершенно разными массивами.

```go
dst := make([]byte, 2)
n := copy(dst, src) // dst — независимая копия первых len(dst) элементов src
```

`copy` — основной инструмент, когда нужно получить данные, не связанные с исходным backing array (см. главы о ловушках подслайсов и об удержании памяти).
