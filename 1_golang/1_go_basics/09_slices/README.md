# Тема 09. Слайсы (Slices)

Этот раздел посвящен изучению слайсов (срезов) в Go: их внутреннему устройству (Slice Header), поведению при `append` и переаллокации массива, утечкам памяти при нарезке и конкурентной безопасности.

## 📋 Пререквизиты

*   Пройдена предыдущая тема: [08_structs](../08_structs/).

> ⏩ **Забегание вперёд.** Некоторые примеры и упражнения используют конструкции из следующих тем:
> *   `08_concurrency_safety` использует горутины и `sync.Mutex` — подробно в [3_concurrency/04_sync_package](../../3_concurrency/04_sync_package/). Задачу можно отложить до этой темы.

    *   [01_basics_len_cap.md](./01_theory/01_basics_len_cap.md) — **основы: массивы vs слайсы, устройство Slice Header (ptr, len, cap), способы создания и передача слайса в функцию**.
    *   [02_append_and_copy.md](./01_theory/02_append_and_copy.md) — эффект `append`, алгоритм роста ёмкости (Go 1.18+) и встроенная функция `copy`.
    *   [03_subslice_pitfalls.md](./01_theory/03_subslice_pitfalls.md) — подслайсы, общий backing array и ловушки при `append` в подслайс.
    *   [04_memory_retention.md](./01_theory/04_memory_retention.md) — утечки памяти при слайсинге и их предотвращение через `copy`.
    *   [05_use_cases.md](./01_theory/05_use_cases.md) — практические сценарии, связывающие теорию с примерами и упражнениями главы.
*   **[02_examples/](./02_examples/)** — практические примеры:
    *   [01_cli_utilities](./02_examples/01_cli_utilities/main.go) — демонстрация побочных эффектов при изменении нарезанных аргументов командной строки и защита данных через `copy()`.
    *   [02_system_infrastructure](./02_examples/02_system_infrastructure/main.go) — симуляция утечки памяти при удержании ссылки на большой backing array и замер использования памяти (разница до/после GC).
    *   [03_product_backend](./02_examples/03_product_backend/main.go) — **современная сортировка и быстрый бинарный поиск по слайсу структур с помощью slices.SortFunc и slices.BinarySearchFunc**.
*   **[03_exercises/](./03_exercises/)** — интерактивные задачи для самопроверки с автопроверками `PASS`/`FAIL`:
    *   `01_slice_basics` — создание слайса заданной длины и емкости с заполнением значениями.
    *   `02_append_capacity` — использование вариативного append для расширения слайса.
    *   `03_copy_delete` — удаление элемента по индексу с сохранением порядка элементов через `copy()`.
    *   `04_subslice_pitfalls` — анализ побочных эффектов при append во вложенный подлайс.
    *   `05_sort_search` — сортировка слайса чисел и бинарный поиск значения с помощью стандартного пакета `slices`.
    *   `06_in_place_ops` — **фильтрация положительных чисел in-place (на месте) без выделения новой памяти (`nums[:0]`)**.
    *   `07_memory_retention` — предотвращение удержания исходного массива в памяти при извлечении первых элементов.
    *   `08_concurrency_safety` — **написание безопасного конкурентного накопителя слайса с помощью sync.Mutex**.
*   **[04_exercises_answers/](./04_exercises_answers/)** — эталонные решения.

## 🚀 Как проходить тему

1. Прочитайте теорию по порядку, начиная с [01_basics_len_cap.md](./01_theory/01_basics_len_cap.md).
2. Запустите и изучите примеры из папки `02_examples/` через `go run`:
   ```bash
   go run ./02_examples/02_system_infrastructure/main.go
   ```
3. Выполните задачи in `03_exercises/`. Запустите встроенный тест для самопроверки:
   ```bash
   go run ./03_exercises/06_in_place_ops/main.go
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.
