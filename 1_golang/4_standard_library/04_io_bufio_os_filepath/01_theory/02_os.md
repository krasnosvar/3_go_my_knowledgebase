# os

Пакет `os` — файлы, переменные окружения, процесс, сигналы.

## Файлы

```go
f, err := os.Open("file.txt")     // read-only
f, err = os.Create("file.txt")    // truncate + create
f, err = os.OpenFile("file.txt", os.O_RDWR|os.O_CREATE, 0644)
defer f.Close()
```

Чтение:

```go
data, err := os.ReadFile("file.txt")  // всё содержимое
```

Запись:

```go
err := os.WriteFile("file.txt", data, 0644)  // atomic-ish: truncate + write
```

Для больших файлов — обычный `Open` + `bufio`.

## Дир-операции

```go
err := os.Mkdir("dir", 0755)
err = os.MkdirAll("a/b/c", 0755)
err = os.Remove("file.txt")
err = os.RemoveAll("dir")

entries, err := os.ReadDir(".")  // []fs.DirEntry
for _, e := range entries {
    fmt.Println(e.Name(), e.IsDir())
}
```

`os.ReadDir` быстрее `ioutil.ReadDir` (старое API) — не вызывает stat.

## Stat / проверка существования

```go
info, err := os.Stat("file.txt")
if errors.Is(err, os.ErrNotExist) { /* нет */ }

info.Size()      // int64
info.Mode()      // права
info.ModTime()
info.IsDir()
```

## Временные файлы/директории

```go
f, _ := os.CreateTemp("", "prefix-*.txt")
defer os.Remove(f.Name())

dir, _ := os.MkdirTemp("", "work-*")
defer os.RemoveAll(dir)
```

## Environment

```go
v := os.Getenv("APP_PORT")                 // "" если нет
v, ok := os.LookupEnv("APP_PORT")          // различаем «нет» и «пусто»
os.Setenv("KEY", "value")
os.Unsetenv("KEY")
envs := os.Environ()                       // []string вида "KEY=VALUE"
```

## Сигналы

```go
import "os/signal"

ctx, stop := signal.NotifyContext(context.Background(), syscall.SIGINT, syscall.SIGTERM)
defer stop()

<-ctx.Done()
// пора выключаться
```

Это лучший способ graceful shutdown (Go 1.16+).

## Args и exit

```go
os.Args    // []string, первый — имя программы
os.Exit(1) // немедленный выход, БЕЗ defer
```

`os.Exit` **не выполняет defer**. В 99% случаев хочется `return` из `main`, а не `os.Exit`.

## Stdin / Stdout / Stderr

```go
fmt.Fprintln(os.Stderr, "error")
io.Copy(dst, os.Stdin)
```

В CLI: данные в stdout, ошибки/логи в stderr.

## Частые ошибки

- Забыть `defer f.Close()` — leak файловых дескрипторов.
- `os.Exit` пропускает defer. Чистка файлов, flush логгеров и метрик не происходит.
- `os.Getenv("X") == ""` может значить и «нет переменной», и «пустая строка». `LookupEnv` если разница важна.
- Работать с путями вручную через `/` вместо `path/filepath.Join` — ломается на Windows.
