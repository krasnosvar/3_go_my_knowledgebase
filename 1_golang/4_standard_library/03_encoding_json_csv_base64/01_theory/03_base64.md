# encoding/base64

Base64 — способ представить бинарные данные в виде ASCII-строки. Нужен, когда транспорт требует текст (JSON, URL, HTTP header, email).

## Какие кодировки

- `base64.StdEncoding` — классический, с `+ /` и паддингом `=`.
- `base64.URLEncoding` — URL-safe: `- _` вместо `+ /`.
- `base64.RawStdEncoding` — без паддинга `=`.
- `base64.RawURLEncoding` — URL-safe без паддинга.

JWT использует `RawURLEncoding` (без паддинга). Для URL-параметров тоже обычно `URLEncoding`.

## Кодирование

```go
data := []byte("hello")
s := base64.StdEncoding.EncodeToString(data)        // "aGVsbG8="
s = base64.URLEncoding.EncodeToString(data)         // тот же, но URL-safe
```

Для потокового кодирования:

```go
enc := base64.NewEncoder(base64.StdEncoding, w)
defer enc.Close() // обязательно — дописывает паддинг
enc.Write(data)
```

## Декодирование

```go
decoded, err := base64.StdEncoding.DecodeString(s)
```

Паттерн с `RawStdEncoding`: если пришла строка без `=` — используй Raw.

## Размер

Base64 увеличивает размер на ~33%. `n` байт → ceil(n/3)*4 символов (плюс паддинг).

Это важно для: максимальной длины URL, размера куки, веса JSON payload'а.

## Типовые use-cases

- **Бинарные данные в JSON**: картинки, криптоключи, токены.
- **URL-safe токены**: session ID, CSRF, magic link.
- **Basic auth**: `Authorization: Basic base64(user:pass)`.
- **JWT**: три части через `.`, каждая — base64url.

## hex как альтернатива

Для более короткого «ключа в логах» / для human-reading иногда берут `encoding/hex`:

```go
s := hex.EncodeToString([]byte{0xde, 0xad, 0xbe, 0xef}) // "deadbeef"
```

Hex — ровно 2× размер (не 1.33×), но читается глазами и копируется без проблем.

## Частые ошибки

- Перепутать `StdEncoding` и `URLEncoding` — разные алфавиты, чужая строка не декодируется.
- Забыть `Close()` для `NewEncoder` — потерять хвост.
- Предполагать, что base64 — это криптография. Это **кодирование**, не шифрование. Любой восстановит исходные байты.
- Использовать для «обфускации» значений — бесполезно и вредно.

## Правило

- JSON payload → `StdEncoding`.
- URL / header → `URLEncoding` или `RawURLEncoding`.
- Нужно хэш/ключ в человекочитаемом виде → `hex`.
