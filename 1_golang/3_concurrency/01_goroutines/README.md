# Изучение goroutines в Go

Goroutine — легковесная единица выполнения в рантайме Go.

## Что важно освоить

- запуск через `go`;
- ожидание завершения (`WaitGroup`, channels);
- ошибка захвата переменной цикла;
- риски утечек goroutines;
- корректная остановка.
