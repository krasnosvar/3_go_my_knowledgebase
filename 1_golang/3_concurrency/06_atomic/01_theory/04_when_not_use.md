# Когда НЕ использовать atomic

Atomic — соблазнительный быстрый инструмент, но у него узкая область применимости.

## 1. Нужно обновить несколько полей согласованно

```go
var (
    count atomic.Int64
    total atomic.Int64
)

count.Add(1)
total.Add(amount) // между этими двумя Add другой горутине видно полусостояние
```

Если критичен инвариант «count и total меняются вместе» — нужен mutex, а не atomic.

## 2. Сложная условная логика

```go
// атомарно: «увеличь, если меньше limit»
for {
    v := n.Load()
    if v >= limit {
        return ErrLimit
    }
    if n.CompareAndSwap(v, v+1) {
        break
    }
}
```

Работает, но читаемость хуже mutex-варианта. Для редких случаев ок, для часто меняющегося условия — mutex и/или пересмотр дизайна.

## 3. Нужна транзакционность с побочными эффектами

Увеличить счётчик, логгировать, послать метрику. Нельзя сделать атомарно без locking-модели: atomic защищает только обновление числа.

## 4. Защита сложной структуры

Map, slice, struct — атомарно не обновить. Варианты:

- `sync.Mutex` / `sync.RWMutex`;
- `atomic.Pointer[T]` + copy-on-write (для read-heavy случаев);
- `sync.Map` для specific map use-cases.

## 5. Когда mutex дешевле

Если контенция низкая, а значение обновляется реже, чем читается — mutex на том же уровне производительности и читается проще. Бенчмаркь перед «оптимизацией».

## 6. Float/complex типы

Atomic работает только с целыми и указателями. Для float/complex — упаковывай в uint64 через `math.Float64bits`:

```go
atomic.StoreUint64(&bits, math.Float64bits(v))
```

Но это уже сигнал: «подумай, почему float должен быть atomic».

## 7. Нужны барьеры памяти нестандартного вида

Go формально имеет упрощённую модель памяти. Если задача требует специфических порядков (acquire/release-барьеров за пределами стандартных operations) — это уже не ниша atomic в Go, может понадобиться свой синхронизатор.

## Правило

Atomic — для простых счётчиков, флагов и snapshot-указателей. Остальное обычно делается через:

- mutex;
- каналы;
- `errgroup` / `sync.WaitGroup`;
- `sync.Once`;
- специализированные библиотеки.
