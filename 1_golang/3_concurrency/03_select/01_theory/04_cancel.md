# Отмена через context в select

Стандартный способ сообщить горутине «пора заканчивать» — `context.Context` с ветвью `<-ctx.Done()` в `select`.

## Базовый шаблон

```go
func worker(ctx context.Context, jobs <-chan Job) error {
    for {
        select {
        case <-ctx.Done():
            return ctx.Err()
        case j, ok := <-jobs:
            if !ok {
                return nil
            }
            if err := process(ctx, j); err != nil {
                return err
            }
        }
    }
}
```

Любая долгоживущая горутина должна иметь такую ветку.

## Цепочка контекстов

HTTP handler создаёт ctx, передаёт в сервис, тот в репозиторий, тот в `db.QueryContext(ctx, ...)`. Один вызов `cancel()` на верхнем уровне останавливает всё внизу.

```go
ctx, cancel := context.WithCancel(ctx)
defer cancel()
```

`cancel()` нужно вызывать всегда, даже если контекст «ушёл сам по таймауту», — иначе остаются подвешенные структуры.

## Различение причин

После отмены:

```go
<-ctx.Done()
err := ctx.Err()
```

- `context.Canceled` — кто-то позвал `cancel()` явно.
- `context.DeadlineExceeded` — исчерпан таймаут.

В лог/метрики полезно различать: отмена — нормальное завершение, таймаут — сигнал о проблеме.

## Отмена как «done» канал

`ctx.Done()` — это канал типа `<-chan struct{}`. Его закрытие — транслируемый сигнал всем, кто слушает. Работает как мультикаст (см. channels/close_and_range).

## Что делать в каждой ветке

```go
select {
case <-ctx.Done():
    // СВОРАЧИВАЕМСЯ: закрыть/освободить ресурсы, вернуть ошибку
    return ctx.Err()
case v := <-ch:
    use(v)
}
```

Важно: не просто выйти, а аккуратно почистить — закрыть файл, откатить транзакцию, остановить тикер.

## Не передавай ctx в struct-ы

`context` — параметр функции, не поле структуры. Исключения есть (`http.Request.Context()`), но в своём коде держи ctx в сигнатурах.

## Правило

- Всякий блокирующий вызов в сервере должен уметь отменяться.
- Всякий `for { select {} }` должен иметь `<-ctx.Done()` ветку.
- Всякая блокирующая отправка в канал — проверяй через select, что не повисла вечно на graceful shutdown.
