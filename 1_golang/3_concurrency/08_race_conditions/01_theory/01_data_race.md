# Data race

**Data race** — ситуация, когда две или более горутин обращаются к одной переменной одновременно, и хотя бы одна из них пишет, без синхронизации.

## Что произойдёт

- Поведение **не определено**. Может «работать», потом сломаться на проде.
- Значение можно прочитать «полусобранным» (особенно для не атомарных типов).
- Компилятор или CPU могут переупорядочить операции так, что наблюдаемая логика не соответствует коду.

## Пример

```go
var counter int

func main() {
    for i := 0; i < 1000; i++ {
        go func() { counter++ }()
    }
    time.Sleep(time.Second)
    fmt.Println(counter) // не 1000, любое значение
}
```

`counter++` — это чтение + запись, между ними другая горутина может подставить своё значение.

## Как обнаружить

Race detector:

```
go run -race ./...
go test -race ./...
```

Обязательно в CI. Без него data race долго остаётся незамеченным.

При обнаружении race-detector печатает стек-трейсы горутин, участвующих в конфликте.

## Частые места

1. Счётчик без atomic/mutex.
2. `map` с параллельным чтением и записью (Go сам паникует при этом в runtime).
3. Общий срез, в который пишут несколько горутин.
4. Инициализация «лениво» через проверку nil.
5. Переменная цикла, захваченная горутиной (см. loop_capture).

## Как исправить

- **Счётчик / флаг**: `sync/atomic` или `sync.Mutex`.
- **Map**: `sync.Mutex` + обычный map, либо `sync.Map` для ряда специальных сценариев.
- **Сложная структура**: mutex или «владение» через канал (одна горутина — единственный писатель).
- **Ленивая инициализация**: `sync.Once`.

## Data race vs race condition

Часто используют как синонимы, но есть разница:

- **Data race** — технический термин, описан выше. Ловит `-race`.
- **Race condition** — более широкое: баг из-за неверных предположений о порядке событий. Может быть без data race (например, «два пользователя нажали кнопку одновременно, и обе кнопки оплатили заказ»).

Все data race — это race condition. Но не все race condition — data race.

## Правило

Любая переменная, с которой работают две или более горутин, **где есть запись**, должна быть защищена. Без исключений.
